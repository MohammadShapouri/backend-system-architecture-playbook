Part 01

Computer Science: The Uniform Access Principle & Encapsulation

In classic object-oriented languages like Java or C++, encapsulation is enforced through rigid language keywords (private, protected, public). Developers are trained to make all fields private and write boilerplate getter and setter methods (getBalance(), setBalance(b)) upfront "just in case" validation logic is needed in the future.

In Python, this is a severe architectural anti-pattern. Python adheres to Bertrand Meyer's Uniform Access Principle:

"All services offered by a module should be available through a uniform notation, which does not betray whether they are implemented through storage or through computation."

In Python, you start with plain, public attributes (user.balance = 100). If business rules later require validation or boundary checks, you refactor the attribute into a @property without changing a single line of caller code!

Public API self.balance

Freely accessible, stable, and documented. Intended for external callers and downstream domain consumers.

Protected Convention self._balance

A strong cultural signal meaning: "Internal implementation detail. Do not touch or mutate from outside this module/class." Not enforced by the compiler ("consenting adults").

Name Mangling self.__balance

CPython rewrites __balance to _ClassName__balance. Its goal is avoiding namespace collisions in deep inheritance trees, not security or true access denial.

Part 02

Under the Hood: Memory Optimization & Schema Sealing with `__slots__`

By default, every Python object instance stores its dynamic attributes inside a private dictionary: instance.__dict__.

While dynamic dictionaries provide absolute flexibility (you can attach new attributes to an object at any moment), they introduce substantial overhead: each instance dictionary consumes ~152 bytes of heap RAM in CPython, plus an 8-byte pointer on the object itself. If your system loads 1,000,000 entities into RAM, you waste over 160MB just on dictionary overhead!

To solve this, Python provides __slots__:

  • Schema Sealing: obj.__dict__ is eliminated. Attempting to assign unlisted attributes raises an immediate AttributeError!
  • Maximum RAM Savings: Attributes are stored directly in a fixed C array of pointers (PyMemberDef), saving 60-70% memory.
  • Hardware Locality: Attribute access operates via direct C struct offset math, avoiding hash table lookups.
Part 03

CPython Internals: The 5-Step Attribute Lookup Pipeline

When you evaluate value = instance.attr, Python does not simply look inside a single dictionary. CPython executes a rigorous 5-step search algorithm governing precedence between descriptors, instance state, and fallback hooks:

The 5-Step Attribute Resolution Algorithm

Trace of the CPython evaluation flow when resolving: instance.attribute

Step 1: Inspect Class & MRO for Data Descriptors Does any class in the MRO define an object with both __get__ AND __set__ (e.g. @property with setter, or member descriptor)?
Priority 1 (Wins Always)
Step 2: Inspect Instance Namespace (__dict__ or __slots__) If no Data Descriptor overrides it, does the key reside directly in instance.__dict__ or a slotted member offset?
Priority 2
Step 3: Inspect Class & MRO for Non-Data Descriptors or Attributes Does the class define a Non-Data Descriptor (e.g. normal method with only __get__) or raw class-level attribute?
Priority 3
Step 4: Invoke __getattr__ Fallback Hook If Steps 1–3 failed to find the attribute, CPython calls instance.__getattr__("attr").
Fallback Hook
Step 5: Raise AttributeError If __getattr__ is not implemented or raises an error, resolution terminates with an exception.
Terminal Exception
Part 04

Dunder Method Matrix: Attribute Routing & Interception

Interception dunders allow you to build dynamic proxies, audit-logging wrappers, and schema validators. Understanding the exact boundary between them is critical to prevent infinite recursion:

Dunder Method Invocation Timing When to Override (✓) When NOT to Override (✗)
__getattr__ Fallback ONLY (Attribute Missing) Delegation wrappers, lazy-loading fields from database, dynamic JSON/dict proxies. Safe and easy to use. When you need to intercept all accesses, including attributes that already exist on the instance.
__getattribute__ Unconditional (Every Attribute Access) Security sandboxes, audit loggers tracking read access, transparent mock frameworks. Must call super().__getattribute__()! Standard attribute access. Accessing self.__dict__ or self.x inside it triggers fatal infinite recursion!
__setattr__ Unconditional (Every Attribute Mutation) Building strictly immutable/frozen domain entities; recording dirty fields; broadcasting change events. Writing self.x = val inside it (causes infinite recursion!). Must delegate to super().__setattr__(name, val).
__delattr__ Unconditional (del instance.attr) Preventing deletion of mandatory domain fields; logging deletion events. Classes where attribute deletion is never permitted (simply raise AttributeError).

# EntityForge Core - Slotted State & Audited Attribute Routing (Milestone 03)

from __future__ import annotations
import time
from typing import Any, Dict, List, Set, Tuple


class SlottedEntityState:
    """
    SLOTTED DOMAIN STATE CONTAINER:
    Eliminates __dict__ overhead by declaring __slots__.
    Enforces a strict closed schema and guards properties with validation.
    """
    __slots__ = ("_name", "_balance", "_is_active")

    def __init__(self, name: str, balance: float, is_active: bool = True) -> None:
        # Use property setters to enforce validation invariants on instantiation
        self.name = name
        self.balance = balance
        self._is_active: bool = is_active

    @property
    def name(self) -> str:
        """Clean public getter for entity name."""
        return self._name

    @name.setter
    def name(self, value: str) -> None:
        """Validates name invariants: Must be a non-empty string."""
        if not isinstance(value, str):
            raise TypeError("Entity name must be a string.")
        cleaned = value.strip()
        if not cleaned:
            raise ValueError("Entity name cannot be empty or blank.")
        self._name = cleaned

    @property
    def balance(self) -> float:
        """Clean public getter for numerical account balance."""
        return self._balance

    @balance.setter
    def balance(self, value: float) -> None:
        """Enforces numerical balance invariants: Negative balances prohibited."""
        if not isinstance(value, (int, float)):
            raise TypeError("Balance must be a numerical float or integer.")
        if value < 0.0:
            raise ValueError(f"Negative balance disallowed: {value}")
        self._balance = float(value)

    @property
    def is_active(self) -> bool:
        return self._is_active


class AuditedAttributeProxy:
    """
    DYNAMIC ATTRIBUTE INTERCEPTION PROXY:
    Wraps an underlying domain object.
    Uses __setattr__ to record dirty mutations, audit logs, and timestamps.
    Prevents infinite recursion by delegating storage strictly to super().__setattr__!
    """
    def __init__(self, target: Any) -> None:
        # CRITICAL: We cannot write self._target = target because that calls __setattr__!
        # We must initialize internal proxy attributes via super().__setattr__:
        super().__setattr__("_target", target)
        super().__setattr__("_dirty_fields", set())
        super().__setattr__("_mutation_log", [])

    def __getattr__(self, name: str) -> Any:
        """
        FALLBACK DELEGATION HOOK:
        Only called if attribute is not found on the proxy itself.
        Forwards transparently to the underlying target entity.
        """
        return getattr(self._target, name)

    def __setattr__(self, name: str, value: Any) -> None:
        """
        MUTATION INTERCEPTION:
        Records old vs new values, flags the field as dirty,
        and applies the mutation to the target object.
        """
        if hasattr(self._target, name):
            old_val = getattr(self._target, name)
            # Apply change to underlying target (triggers property validation if present)
            setattr(self._target, name, value)
            
            # Record audit trail
            self._dirty_fields.add(name)
            self._mutation_log.append({
                "field": name,
                "old_value": old_val,
                "new_value": value,
                "timestamp": time.time()
            })
        else:
            # Set internal attribute on proxy via super()
            super().__setattr__(name, value)

    def get_dirty_fields(self) -> Set[str]:
        """Returns all attribute names modified during this proxy session."""
        return set(self._dirty_fields)

    def flush_dirty(self) -> None:
        """Clears the dirty set after persisting changes to database storage."""
        self._dirty_fields.clear()

import pytest
from entityforge.core.state import SlottedEntityState, AuditedAttributeProxy


class TestStateEncapsulation:
    """Unit tests asserting property guards, __slots__ schema sealing, and proxy tracking."""

    def test_property_getters_and_setters_enforce_validation(self):
        state = SlottedEntityState(name="Vault_Alpha", balance=500.0)

        # 1. Access properties via uniform access notation
        assert state.name == "Vault_Alpha"
        assert state.balance == 500.0
        assert state.is_active is True

        # 2. Mutate properties via setter validation
        state.name = "   Vault_Beta   "
        assert state.name == "Vault_Beta"  # Stripped!

        state.balance = 1250.75
        assert state.balance == 1250.75

        # 3. Assert validation barriers reject bad types and values
        with pytest.raises(ValueError, match=r"Negative balance disallowed"):
            state.balance = -50.0

        with pytest.raises(TypeError, match=r"Balance must be a numerical"):
            state.balance = "invalid_number"

        with pytest.raises(ValueError, match=r"Entity name cannot be empty"):
            state.name = "    "

    def test_slots_prevents_arbitrary_attributes_and_eliminates_dict(self):
        state = SlottedEntityState(name="Secure_Vault", balance=100.0)

        # 1. Assert __dict__ does NOT exist on the slotted instance
        assert not hasattr(state, "__dict__")

        # 2. Attempting to assign unlisted arbitrary attributes raises AttributeError!
        with pytest.raises(AttributeError):
            state.unregistered_hack = "exploit"

    def test_audited_attribute_proxy_mutation_tracking(self):
        underlying = SlottedEntityState(name="Account_01", balance=1000.0)
        proxy = AuditedAttributeProxy(underlying)

        # Initially no dirty fields
        assert proxy.get_dirty_fields() == set()

        # Transparent read access delegates via __getattr__
        assert proxy.name == "Account_01"
        assert proxy.balance == 1000.0

        # Mutate through proxy
        proxy.balance = 1500.0
        assert underlying.balance == 1500.0
        assert proxy.get_dirty_fields() == {"balance"}

        # Check mutation history log
        assert len(proxy._mutation_log) == 1
        log_entry = proxy._mutation_log[0]
        assert log_entry["field"] == "balance"
        assert log_entry["old_value"] == 1000.0
        assert log_entry["new_value"] == 1500.0

        # Flushing resets dirty tracking
        proxy.flush_dirty()
        assert proxy.get_dirty_fields() == set()
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Infinite Recursion in __setattr__ / __getattribute__

Writing def __setattr__(self, name, val): self.name = val.

Why this crashes the interpreter: Assigning self.name = val invokes __setattr__ again, which calls __setattr__ again, triggering an inescapable loop until Python crashes with RecursionError: maximum recursion depth exceeded! Fix: Always delegate to the base class via super().__setattr__(name, val).

❌ Heavy / Slow Operations in Properties

Writing @property def user_orders(self): return db.query(...).

Why this causes severe performance bugs: Python programmers expect attribute access (obj.field) to be an instant $O(1)$ in-memory operation. Hiding slow database queries or network HTTP calls behind a property causes developers to write for item in obj.user_orders:, unexpectedly executing hundreds of queries inside loops! Use an explicit method like def fetch_user_orders() instead.

❌ The Slotted Multiple Inheritance Layout Conflict

Inheriting from two parent classes that both define non-empty __slots__.

Why this fails at definition time: At the C level, CPython cannot merge two distinct struct member offset arrays into a single instance, immediately raising TypeError: multiple bases have instance lay-out conflict! If designing mixins intended for multiple inheritance, leave their slots empty: __slots__ = ().

❌ Java-Style Trivial Getter / Setter Bloat

Writing explicit get_name() and set_name(val) methods without any validation logic.

Why this is unpythonic: It clutters the API with hundreds of lines of useless boilerplate code. Because Python provides the Uniform Access Principle via @property, start with a plain public attribute self.name = name. You can transparently promote it to a property setter later if validation becomes necessary!
