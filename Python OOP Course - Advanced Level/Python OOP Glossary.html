A Index

Abstract Base Class (ABC)

Contract • Ch. 10

A class inheriting from abc.ABC that enforces implementation contracts via nominal subtyping. CPython inspects __abstractmethods__ and halts instantiation with TypeError if any decorated method remains unfulfilled.

@abstractmethod

Decorator • Ch. 10

A decorator from abc setting __isabstractmethod__ = True on a function. Must sit as the innermost decorator directly above the def statement when combined with @classmethod or @property.

Aggregation ("Has-a")

Relationship • Ch. 08

A class relationship where a container object holds a reference to an external entity with an independent lifecycle (e.g. an Order aggregates a Customer). Deleting the order leaves the customer entity completely unharmed.

Anemic Domain Model

Anti-Pattern • Ch. 13

An architectural code smell where entities are reduced to dumb data structures containing zero business logic (just attributes/getters), while domain validation and calculations are scattered across procedural "service" functions.

Association ("Knows-a")

Relationship • Ch. 08

The weakest form of class coupling where an object interacts with another transiently, typically by receiving it as a method parameter (e.g. OrderService invokes EmailNotifier). Neither object owns the other.

Attribute Lookup Pipeline

CPython • Ch. 03

The 5-step search algorithm CPython runs on inst.attr: 1. Data Descriptors in Class/MRO → 2. Instance __dict__ / Slot → 3. Non-Data Descriptors / Class Attributes → 4. __getattr__ Fallback → 5. AttributeError.

B Index

BaseEntity (EntityForge)

EntityForge • Ch. 01

The foundational root entity metamodel engineered in Milestone 01. Enforces immutable UUID identity (EntityIdentity), separates instance state from schema namespaces, and provides polymorphic create_new() factory constructors.

Bound Method

CPython • Ch. 01

A lightweight CPython wrapper (PyMethodObject) returned when a class function's __get__ descriptor binds to an instance. Binds two internal pointers: __self__ (instance) and __func__ (raw function).

Builder Pattern

Creational • Ch. 14

A creational design pattern that builds complex aggregate roots step-by-step using a fluent API (.for_customer().add_item().build()). Prevents telescoping constructor anti-patterns with dozen-argument __init__ calls.

__bytes__(self)

Protocol • Ch. 04

A special method invoked by bytes(obj) returning the binary wire representation of an object. Used for packing C structs, streaming into binary WAL buffers, or cryptographic hashing.

C Index

C3 Linearization Algorithm

Algorithm • Ch. 09

The mathematical merge algorithm used by Python (since 2.3) to linearize class inheritance DAGs into a deterministic Method Resolution Order (MRO). Enforces monotonicity, local precedence, and extended precedence.

__call__(self, *args, **kw)

Protocol • Ch. 07

A dunder method transforming any class instance into a first-class callable object (instance()). Ideal for stateful pipeline operators, strategy patterns, and state-preserving parameterizable decorators.

@classmethod

Decorator • Ch. 01

A built-in decorator wrapping a function into a descriptor that automatically binds the class object as cls instead of an instance. The standard Python mechanism for alternative named constructors and polymorphic factory methods.

Clean Architecture

Architecture • Ch. 13

A software design paradigm organizing systems into concentric circles where dependencies point strictly inward. Core domain entities remain isolated from frameworks, databases, and third-party APIs via abstract protocols.

Composition ("Contains-a")

Relationship • Ch. 08

The tightest association relationship where an owner completely manages the lifecycle of internal child entities (e.g. an Order composes OrderLine items). If the parent order is destroyed, all child lines are destroyed with it.

Context Manager Protocol

Protocol • Ch. 07

The pair of dunder methods (__enter__ and __exit__) governing the with statement. Guarantees deterministic resource acquisition and teardown regardless of whether exceptions occur in the block.

D Index

Data Descriptor

Descriptor • Ch. 11

A descriptor defining __set__ or __delete__. In CPython's lookup precedence, Data Descriptors strictly override instance __dict__ entries, making them the premier tool for ORM field validation.

__del__(self)

Finalizer • Ch. 02

The CPython object finalization dunder. Highly hazardous in application code: execution timing is non-deterministic, exceptions inside it are silenced, and assigning self to an outer scope resurrects zombie instances. Prefer Context Managers.

Delegation Pattern

Design Pattern • Ch. 08

An architectural technique where an outer wrapper object transparently forwards unhandled method calls to an internal composed object via __getattr__. Provides clean behavioral extension without inheritance coupling.

Dependency Inversion (DIP)

SOLID • Ch. 13

The 'D' in SOLID: High-level business modules should not import low-level infrastructure drivers; both must depend on abstract Protocols or ABCs. Realized via Constructor Dependency Injection.

Descriptor Protocol

Protocol • Ch. 11

The CPython attribute customization protocol consisting of __get__, __set__, __delete__, and PEP 487 __set_name__. Powers methods, properties, and declarative ORM validation engines.

Duck Typing

Polymorphism • Ch. 10

"If it walks like a duck and quacks like a duck, it's a duck." Python's runtime philosophy where an object's suitability is determined by the presence of specific methods and properties rather than its explicit inheritance lineage.

E Index

Encapsulation

Concept • Ch. 03

The bundling of data state with methods operating on that state, restricting direct unauthorized tampering. In Python, enforced idiomatically via protected conventions (_attr), properties, and descriptors rather than private compiler keywords.

EntityForge Project

Capstone • Ch. 01–14

The enterprise, event-driven domain modeling, plugin, and workflow orchestration engine built incrementally across all 14 chapters to demonstrate production-grade Python OOP architecture.

__eq__(self, other)

Protocol • Ch. 05

The rich comparison operator governing a == b. Must return NotImplemented when comparing against unexpected foreign types to allow CPython to reflect the operator to the other operand.

F Index

@final (typing.final)

Decorator • Ch. 01

A typing decorator (PEP 591) informing static type checkers (mypy, pyright) that a method must not be overridden or a class must not be subclassed. Guards sensitive core invariants.

Flyweight Pattern

Creational • Ch. 02

A creational design pattern minimizing memory footprint by sharing identical immutable instances across the process. In Python, implemented in __new__ by intercepting creation and returning cached pointers.

__format__(self, format_spec)

Protocol • Ch. 04

A dunder method invoked by f-strings (f"{obj:spec}") and format(). Enables domain models to parse custom mini-languages (e.g. :compact, :json, :masked).

Fragile Base Class

Anti-Pattern • Ch. 08

An architectural vulnerability inherent in deep inheritance hierarchies where seemingly benign modifications to base class private methods cause silent cascading regressions across distant subclasses.

G Index

__getattr__(self, name)

Protocol • Ch. 03, 08

A fallback attribute lookup hook called by CPython strictly when the attribute is not found on the instance, class, or base classes. The standard tool for transparent forwarding proxies.

__getattribute__(self, name)

Protocol • Ch. 03

The unconditional attribute access dunder invoked on every single attribute read. Must delegate to super().__getattribute__() to avoid immediate infinite recursion crashes.

God Object (The Blob)

Anti-Pattern • Ch. 13

A monolithic class that knows too much and does too much (e.g. an OrderManager that handles validation, SQL generation, Stripe payments, and PDF creation), severely violating the Single Responsibility Principle.

H Index

__hash__(self)

Protocol • Ch. 05

Computes an integer hash code enabling instances to serve as dictionary keys and set elements. Must return an immutable value such that if a == b, then hash(a) == hash(b) holds true.

Hash-Equality Contract

Contract • Ch. 05

The mathematical invariant dictating that if two objects evaluate as equal under __eq__, their __hash__ outputs must be strictly identical throughout their entire lifecycle to guarantee hash table bucket discovery.

I Index

Identity (`is`) vs. Equality (`==`)

Axiom • Ch. 01

Identity (is): Evaluates if two variables point to the exact same memory address pointer. Equality (==): Evaluates whether two distinct instances share equivalent semantic state.

__init__(self, *args, **kw)

Protocol • Ch. 02

The instance initializer dunder called by type.__call__ in Phase 2 of object construction. Assigns instance state and must return strictly None.

__init_subclass__(cls, **kwargs)

PEP 487 • Ch. 12

A classmethod hook (PEP 487) executed whenever a class is subclassed. Replaces 95% of custom metaclass use cases by providing clean subclass registration and header keyword argument handling without MRO conflicts.

Interface Segregation (ISP)

SOLID • Ch. 13

The 'I' in SOLID: Clients should not be forced to depend on methods they do not use. In Python, realized by authoring small, highly focused typing.Protocol interfaces rather than monolithic base classes.

L Index

Liskov Substitution (LSP)

SOLID • Ch. 13

The 'L' in SOLID: Subtypes must be completely substitutable for their base types without altering system correctness. Subclasses must never tighten preconditions, weaken postconditions, or throw unhandled exceptions.

M Index

Metaclass

Metaprogramming • Ch. 12

The class of a class. In Python, classes are instances of metaclasses (type by default). Metaclasses intercept class definition to compile schemas, inspect descriptors, and register models.

Method Resolution Order (MRO)

CPython • Ch. 09

The linear sequence of classes CPython searches when resolving attribute and method lookups. Stored on the class as __mro__ and calculated via the C3 Linearization algorithm.

Mixin

Design Pattern • Ch. 08

A specialized, strictly stateless class intended to inject reusable behavioral methods across unrelated class hierarchies via multiple inheritance without representing an independent domain entity.

MonetaryAmount (EntityForge)

EntityForge • Ch. 05

The immutable, slotted Value Object engineered in Milestone 05. Combines decimal.Decimal precision with Flyweight currency tokens, enforcing total ordering, currency mismatch guards, and mathematical hash invariants.

N Index

Name Mangling

CPython • Ch. 03

CPython's identifier rewriting mechanism for attributes prefixed with two leading underscores (__attr → _ClassName__attr). Designed to prevent attribute collisions in deep inheritance trees, not for security.

__new__(cls, *args, **kw)

Protocol • Ch. 02

The static memory allocator dunder executed in Phase 1 of object construction. Carves out heap memory and returns the uninitialized instance. Overridden when customizing immutable types, implementing Flyweight pools, or dynamic subclass routing.

Non-Data Descriptor

Descriptor • Ch. 11

A descriptor defining __get__ only (no __set__). In CPython's lookup precedence, Non-Data Descriptors yield to instance __dict__ entries, which is why instance attributes can shadow methods.

NotImplemented Singleton

CPython • Ch. 05

A special built-in singleton returned by comparison and binary arithmetic dunders indicating that the type does not know how to interact with the operand, instructing CPython to reflect the operation (a < b → b > a).

O Index

object

CPython • Ch. 01

The ultimate root of Python's inheritance tree. Every class in Python 3 implicitly or explicitly subclasses object, inheriting basic pointer comparison, hashing, and string fallback routines.

Observer Pattern (Event Bus)

Behavioral • Ch. 14

A behavioral design pattern decoupling event producers from side-effect consumers. Entities broadcast state changes as domain events without knowing what logging, analytics, or notification services consume them.

Open/Closed Principle (OCP)

SOLID • Ch. 13

The 'O' in SOLID: Software entities should be open for extension, but closed for modification. In Python, achieved by injecting pluggable strategy protocols rather than modifying classes with branching type ladders.

@override (typing.override)

Decorator • Ch. 01

A typing decorator (PEP 698) indicating to static type checkers that a method is intended to override a parent method. Protects against silent refactoring regressions where parent method signatures change.

P Index

Polymorphism

Concept • Ch. 01, 10

The capability of different classes to respond to the same method interface. In Python, realized through dynamic dispatch, dunder operator overloading, and structural duck typing (typing.Protocol).

Primitive Obsession

Anti-Pattern • Ch. 13

An architectural code smell where developers pass raw scalars (strings, floats, dicts) everywhere instead of encapsulating business rules into self-validating, immutable Value Objects (e.g. MonetaryAmount).

@property Decorator

Encapsulation • Ch. 03

Python's built-in data descriptor wrapping methods into clean attribute accessors (.getter, .setter, .deleter), honoring the Uniform Access Principle without boilerplate Java getters/setters.

Protocol (typing.Protocol)

PEP 544 • Ch. 10

Modern Python's structural interface standard (PEP 544). Classes satisfy protocols by matching method shapes and signatures with zero inheritance coupling.

PyObject

CPython • Ch. 01

The base C structure underlying all Python objects. Contains the reference count (ob_refcnt) and the type pointer (ob_type) addressing the object's class on the heap.

R Index

Reentrant Context Manager

Architecture • Ch. 07

A context manager that safely supports nested with blocks using an internal depth counter. Manages resources so that nested scopes create sub-savepoints without prematurely closing the physical resource.

__repr__(self)

Protocol • Ch. 04

The primary developer diagnostic string dunder. Must be unambiguous, display class name and key attributes, and where feasible satisfy eval(repr(obj)) == obj. Displayed in debuggers, exceptions, and container printing.

@runtime_checkable

Decorator • Ch. 10

A decorator from typing enabling a Protocol to be used with runtime isinstance() and issubclass() by synthesizing a structural __subclasshook__.

S Index

__set_name__(self, owner, name)

PEP 487 • Ch. 11

A descriptor callback (PEP 487) automatically called by CPython at class creation time. Informs the descriptor of the exact variable identifier it was assigned to, eliminating duplicate naming boilerplate.

Single Responsibility (SRP)

SOLID • Ch. 13

The 'S' in SOLID: A class should have one, and only one, reason to change. In Python, separating domain entity rules from persistence, HTML serialization, and external API communication.

__slots__

Memory • Ch. 03

A class-level declaration that replaces dynamic instance dictionaries (__dict__) with fixed C-array member descriptors, slashing memory usage by 65% and preventing arbitrary unvalidated attribute assignment.

State Pattern

Behavioral • Ch. 14

A behavioral design pattern modeling lifecycle workflows by encapsulating state-dependent behavior in polymorphic state objects. Replaces nested if status == ... conditional branches.

@staticmethod

Decorator • Ch. 01

A built-in decorator that strips the automatic binding of self or cls. Groups pure utility functions within a class namespace for logical cohesion.

__str__(self)

Protocol • Ch. 04

The user-facing string representation dunder invoked by str(), print(), and bare f-strings. Prioritizes readability over exhaustive technical diagnostics.

super()

Built-in • Ch. 09

A built-in proxy object that delegates method calls to the next class in the runtime MRO sequence. Does not simply call the parent class, enabling cooperative multiple inheritance chains.

T Index

@functools.total_ordering

Decorator • Ch. 05

A class decorator from functools that synthesizes all remaining rich comparison methods when a class defines __eq__ and one ordering method (e.g. __lt__).

type

Metaclass • Ch. 01, 12

The root metaclass in CPython. Subclasses object while being an instance of itself. Its 3-argument form type(name, bases, dict) dynamically manufactures classes at runtime.

type.__call__

CPython • Ch. 02

The C-level metaclass call operator orchestrating the two-phase construction protocol: invokes __new__ to allocate memory, verifies type invariants, and conditionally dispatches __init__.

U Index

Uniform Access Principle

Principle • Ch. 03

The architectural law stating that services offered by an object should be accessed via uniform notation whether implemented via storage or computation. Explains why Java-style getters/setters are an anti-pattern in Python.

Unhashable Type

Error • Ch. 02, 05

An object whose class sets __hash__ = None (automatically applied when __eq__ is implemented without __hash__). Raising TypeError if added to a set or dictionary.

V Index

Value Object (DDD)

DDD • Ch. 05

A Domain-Driven Design object defined strictly by the equality of its attribute values rather than a unique identity thread. Strictly immutable, hashable, and interchangeable.

Virtual Subclass

ABCs • Ch. 10

A class registered with an ABC via ABC.register(Class) or recognized by __subclasshook__. Evaluates as isinstance() True without appearing in the MRO.

W Index

Weak Reference (weakref)

Memory • Ch. 02, 03

A reference that points to an object without incrementing its reference count (ob_refcnt). Allows caching objects without preventing garbage collection.

Z Index

Zombie Resurrection

CPython Bug • Ch. 02

A runtime hazard where code inside a finalizer (__del__) assigns self to an external global variable, reviving an object during active C-level deallocation.
