Part 01

Computer Science: Python's Secret Engine

Most developers believe that Python features like methods, @property, @classmethod, and @staticmethod are hardcoded language primitives built directly into the CPython grammar.

In reality, they are all powered by a single underlying protocol: the Descriptor Protocol. A descriptor is simply an object that customizes attribute access by implementing at least one of the following special methods:

__get__(self, instance, owner) Invoked when the attribute is read. Receives the calling instance (or None if accessed via the class) and the owner class.
__set__(self, instance, value) Invoked when an attribute assignment occurs: instance.attr = value. Defines mutation and validation rules.
__delete__(self, instance) Invoked when del instance.attr is executed. Manages state destruction or prevents field deletion.
Precedence Hierarchy: Data Descriptors vs. Non-Data Descriptors
1. Data Descriptor Defines __set__ or __delete__
  • Priority: Wins over instance __dict__! If a class defines a Data Descriptor named age, setting instance.__dict__['age'] = 99 is ignored during reads; __get__ is executed unconditionally!
  • Built-in Examples: @property (when a setter is defined), __slots__ member descriptors, and ORM fields.
class Field: def __get__(); def __set__()
2. Non-Data Descriptor Defines __get__ ONLY
  • Priority: Yields to instance __dict__! If an entry with the same name exists in instance.__dict__, the dictionary value shadows the descriptor completely.
  • Built-in Examples: Standard functions/methods, @classmethod, and @staticmethod. (This is why you can monkey-patch methods on a specific instance!).
class Method: def __get__() # No __set__
Part 02

Under the Hood: PEP 487 & The `__set_name__` Revolution

Prior to Python 3.6, writing custom descriptors suffered from an infamous ergonomics problem: descriptors did not know what attribute name they were assigned to on the class!

Developers had to write redundant boilerplate, passing the variable name twice: username = StringField("username"). Alternatively, complex frameworks like Django and SQLAlchemy were forced to use heavy metaclasses to inspect the class dictionary at definition time and inject the names.

PEP 487 solved this permanently by introducing the __set_name__(self, owner, name) callback:

The Automated __set_name__ Handshake During Class Creation
1. Class Body Execution Python executes the class body. Descriptors are instantiated: email = EmailField().
Phase 1
2. CPython Type Construction type.__new__ constructs the new class object (UserEntity).
Phase 2
3. Automated PEP 487 Callback (__set_name__) CPython scans the class dictionary and calls descriptor.__set_name__(UserEntity, "email") automatically!
PEP 487 Auto-Hook
// Why This Matters in Senior Architecture:

The descriptor dynamically learns its own attribute identifier (name = "email") and computes its private instance storage key (self._storage_name = f"_{name}") with zero user input, zero duplication, and zero metaclass complexity!

Part 03

Storage Strategies: Solving the Shared-State Memory Leak

When a developer writes their first custom descriptor, they almost always fall into the Shared-State Memory Leak Trap:

✗ The Fatal Shared State Trap Catastrophic Leak 
class BrokenField:
    def __set__(self, instance, value):
        self.val = value  # FATAL: Stored on the descriptor instance!

    def __get__(self, instance, owner):
        return self.val

Why this causes production outages: Descriptors are instantiated once at the class level. There is only one single descriptor instance shared across all 100,000 entity instances! Setting user_b.name = "Bob" overwrites user_a.name!

✓ Production Instance Storage Instance Isolated 
class ProductionField:
    def __set_name__(self, owner, name):
        self.storage_name = f"_{name}"

    def __set__(self, instance, value):
        # Store state inside the specific instance's __dict__:
        instance.__dict__[self.storage_name] = value

    def __get__(self, instance, owner):
        if instance is None:
            return self  # Class-level access guard
        return instance.__dict__.get(self.storage_name)

State is strictly stored in instance.__dict__ under a protected name. Each instance maintains completely isolated data, with zero cross-instance pollution!

Part 04

Dunder Method Matrix: The Complete Descriptor Protocol

The full contractual specification for Python descriptors:

Method Invocation Timing When to Override (✓) When NOT to Override (✗)
__set_name__ __set_name__(self, owner, name) Mandatory for reusable field descriptors. Captures the attribute name automatically at class construction time and prepares instance storage keys. Ad-hoc descriptor instances created dynamically at runtime after class construction has already finished.
__get__ __get__(self, instance, owner) Reading attribute values, computing dynamic transformations, binding methods. Must always check if instance is None: return self! Descriptors that strictly handle write-only logging or write-only security authorization guards.
__set__ __set__(self, instance, value) Type enforcement, range/boundary validation, dirty-flag tracking, ORM data conversion. Transforms the descriptor into a Data Descriptor. Read-only cached properties (use a Non-Data descriptor so the computed value can be cached directly in instance.__dict__).
__delete__ __delete__(self, instance) Cleaning up storage slots on del instance.attr, clearing foreign-key relational caches, or strictly raising AttributeError to block field deletion. Standard models where attribute deletion is simply ignored or not part of the business domain.

1. Production Descriptors Core: src/entityforge/core/descriptors.py PEP 487 Declarative Validation Engine 
# ==============================================================================
# EntityForge Core - Declarative Descriptors & Validation Engine (Milestone 11)
# ==============================================================================

from __future__ import annotations
import re
from abc import ABC, abstractmethod
from typing import Any, Optional, Self, Type
from entityforge.core.entity import BaseEntity, EntityIdentity


class Field(ABC):
    """
    ABSTRACT DATA DESCRIPTOR BASE CLASS:
    Implements PEP 487 __set_name__, isolated instance storage, and deletion guards.
    """
    def __init__(self, default: Any = None, required: bool = True) -> None:
        self.default = default
        self.required = required
        self.field_name: str = ""
        self.storage_name: str = ""

    def __set_name__(self, owner: Type[Any], name: str) -> None:
        """
        PEP 487 AUTOMATED BINDING:
        CPython calls this at class creation time, injecting the attribute name.
        """
        self.field_name = name
        # Prefix with protected underscore to isolate storage in instance __dict__
        self.storage_name = f"_{name}"

    def __get__(self, instance: Optional[Any], owner: Type[Any]) -> Any:
        """
        CLASS-LEVEL ACCESS GUARD:
        If accessed from class (e.g. User.email), return descriptor instance itself!
        If accessed from instance (user.email), return stored value.
        """
        if instance is None:
            return self
        
        return instance.__dict__.get(self.storage_name, self.default)

    def __set__(self, instance: Any, value: Any) -> None:
        """Validates value and stores in instance.__dict__ directly."""
        if value is None:
            if self.required:
                raise ValueError(f"Field '{self.field_name}' is mandatory and cannot be None.")
            instance.__dict__[self.storage_name] = None
            return

        # Execute subclass-specific domain validation
        validated_value = self.validate(value)
        instance.__dict__[self.storage_name] = validated_value

    def __delete__(self, instance: Any) -> None:
        """Blocks attribute deletion to maintain domain schema invariants."""
        raise AttributeError(f"Cannot delete mandatory field '{self.field_name}'.")

    @abstractmethod
    def validate(self, value: Any) -> Any:
        """Subclasses must implement domain validation logic."""
        pass


class StringField(Field):
    """Validates string types, length boundaries, and non-empty invariants."""
    def __init__(
        self,
        min_length: int = 1,
        max_length: Optional[int] = None,
        default: Any = None,
        required: bool = True
    ) -> None:
        super().__init__(default=default, required=required)
        self.min_length = min_length
        self.max_length = max_length

    def validate(self, value: Any) -> str:
        if not isinstance(value, str):
            raise TypeError(f"Field '{self.field_name}' must be a str, got '{type(value).__name__}'.")
        
        cleaned = value.strip()
        if len(cleaned) < self.min_length:
            raise ValueError(f"Field '{self.field_name}' length must be >= {self.min_length}.")
        if self.max_length and len(cleaned) > self.max_length:
            raise ValueError(f"Field '{self.field_name}' length must be <= {self.max_length}.")
        
        return cleaned


class IntegerField(Field):
    """Validates integer types and numerical bounds."""
    def __init__(
        self,
        min_value: Optional[int] = None,
        max_value: Optional[int] = None,
        default: Any = None,
        required: bool = True
    ) -> None:
        super().__init__(default=default, required=required)
        self.min_value = min_value
        self.max_value = max_value

    def validate(self, value: Any) -> int:
        if not isinstance(value, int) or isinstance(value, bool):
            raise TypeError(f"Field '{self.field_name}' must be an int, got '{type(value).__name__}'.")
        
        if self.min_value is not None and value < self.min_value:
            raise ValueError(f"Field '{self.field_name}' must be >= {self.min_value}.")
        if self.max_value is not None and value > self.max_value:
            raise ValueError(f"Field '{self.field_name}' must be <= {self.max_value}.")
        
        return value


class EmailField(StringField):
    """Enforces email formatting using regular expression matching."""
    EMAIL_REGEX = re.compile(r"^[\w\.-]+@[\w\.-]+\.\w+$")

    def validate(self, value: Any) -> str:
        cleaned = super().validate(value)
        if not self.EMAIL_REGEX.match(cleaned):
            raise ValueError(f"Field '{self.field_name}' has invalid email format: '{cleaned}'")
        return cleaned.lower()


class DeclarativeEntityModel(BaseEntity):
    """
    DECLARATIVE BASE MODEL:
    Allows entities to declare descriptors at the class level and automatically
    populates them during initialization with full validation.
    """
    def __init__(self, entity_id: EntityIdentity, **kwargs: Any) -> None:
        super().__init__(entity_id=entity_id)
        # Assign attributes through descriptors to trigger __set__ validation
        for key, val in kwargs.items():
            setattr(self, key, val)

import pytest
from entityforge.core.entity import EntityIdentity
from entityforge.core.descriptors import (
    DeclarativeEntityModel,
    StringField,
    IntegerField,
    EmailField,
    Field,
)


class UserProfile(DeclarativeEntityModel):
    """Declarative domain model defined with reusable field descriptors."""
    username = StringField(min_length=3, max_length=20)
    age = IntegerField(min_value=18, max_value=120)
    email = EmailField()


class TestDescriptorValidationEngine:
    """Unit tests asserting PEP 487 naming, data isolation, validation, and class access."""

    def test_pep_487_set_name_captures_field_identifiers(self):
        # Descriptors must automatically learn their class-level variable names
        assert UserProfile.username.field_name == "username"
        assert UserProfile.username.storage_name == "_username"
        assert UserProfile.email.field_name == "email"
        assert UserProfile.email.storage_name == "_email"

    def test_class_level_access_returns_descriptor_instance(self):
        # CRITICAL INTROSPECTION INVARIANT:
        # Accessing descriptor via Class MUST return the descriptor instance itself!
        assert isinstance(UserProfile.username, StringField)
        assert isinstance(UserProfile.email, EmailField)

    def test_valid_model_instantiation_and_isolation(self):
        id1 = EntityIdentity.generate()
        id2 = EntityIdentity.generate()

        user1 = UserProfile(id1, username="alice", age=28, email="Alice@Example.com")
        user2 = UserProfile(id2, username="bob_dev", age=35, email="bob@test.org")

        # 1. State properly initialized and normalized
        assert user1.username == "alice"
        assert user1.age == 28
        assert user1.email == "alice@example.com"  # Lowercased by EmailField

        # 2. DATA ISOLATION INVARIANT:
        # User 2 mutations must NEVER bleed into User 1!
        assert user2.username == "bob_dev"
        assert user2.age == 35

        user1.age = 29
        assert user1.age == 29
        assert user2.age == 35  # User 2 untouched!

    def test_validation_boundaries_raise_expected_errors(self):
        ident = EntityIdentity.generate()

        # 1. StringField length violations
        with pytest.raises(ValueError, match=r"username' length must be >="):
            UserProfile(ident, username="al", age=20, email="a@b.com")

        # 2. IntegerField bounds violations
        with pytest.raises(ValueError, match=r"age' must be >="):
            UserProfile(ident, username="alice", age=17, email="a@b.com")

        # 3. EmailField format violations
        with pytest.raises(ValueError, match=r"invalid email format"):
            UserProfile(ident, username="alice", age=25, email="not-an-email")

    def test_descriptor_deletion_is_blocked(self):
        user = UserProfile(EntityIdentity.generate(), username="alice", age=25, email="a@b.com")

        # __delete__ blocks attribute deletion
        with pytest.raises(AttributeError, match=r"Cannot delete mandatory field"):
            del user.email
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Infinite Recursion in Descriptor Methods

Writing setattr(instance, self.field_name, value) inside __set__.

Why this crashes the process: Calling setattr() with the public attribute name invokes the descriptor's __set__ method again, which calls setattr() again, triggering an immediate RecursionError! Always store state under a private mangled storage key inside instance.__dict__[self.storage_name] = value.

❌ Omitting the 'instance is None' Guard in __get__

Implementing __get__ without checking if instance is None: return self.

Why this breaks frameworks: When ORMs, documentation generators, or schema introspectors inspect the model via the class (e.g. UserProfile.email), instance is None. Omitting this check raises an immediate AttributeError: 'NoneType' object has no attribute '__dict__'!

❌ Instantiating Descriptors in __init__

Writing self.name = StringField() inside __init__.

Why descriptors fail on instances: CPython's descriptor lookup mechanism only activates when descriptors are declared at the CLASS level! If you attach a descriptor to an instance, Python treats it as a plain, inert object attribute and never calls __get__ or __set__.

❌ The Shared Descriptor Memory Leak

Storing state on the descriptor instance itself: self.value = value.

Why this causes data corruption: There is only one descriptor instance shared across all entity instances. Mutating self.value leaks state across all users and causes subtle, hard-to-diagnose race conditions!
