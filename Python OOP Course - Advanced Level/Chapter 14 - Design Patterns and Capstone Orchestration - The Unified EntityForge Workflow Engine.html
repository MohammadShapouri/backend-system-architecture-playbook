Part 01

Computer Science: Design Patterns Reimagined for Python

When the Gang of Four (GoF) published Design Patterns in 1994, their implementations addressed structural limitations in C++ and early Smalltalk. In Python, first-class functions, descriptors, dynamic typing, and duck typing make many classic patterns either built-in language features or vastly simpler to construct:

1. State Pattern Behavioral

Encapsulates state-dependent behavior inside discrete polymorphic classes (DraftState, SubmittedState, ApprovedState).

Anti-Pattern Defused: Replaces giant, unmaintainable if status == "DRAFT": ... elif status == "PENDING": ... branching ladders across dozens of methods.

2. Observer Pattern Behavioral

Decouples event producers from side-effect consumers (logging, analytics, emails, cache invalidation) via a publish-subscribe Domain Event Bus.

Python Advantage: Callables, bound methods, and lambda expressions can be registered directly without implementing verbose listener interfaces.

3. Builder Pattern Creational

Constructs complex, multi-part domain aggregates step-by-step through a fluent API, enforcing invariants before finalizing the instance.

Clean Construction: Eliminates confusing "telescoping constructors" with 12 optional arguments inside __init__.

Part 02

Under the Hood: Polymorphic Lifecycle State Machines

A common code smell in enterprise backends is managing workflow transitions using raw string status flags (self.status = "PENDING"). As business rules grow, every method ends up repeating conditional guards:

if self.status != "DRAFT": raise InvalidStateError("Can only edit drafts")
if self.status == "APPROVED": raise InvalidStateError("Already approved")
# Repeated across 15 different entity methods!

The State Pattern solves this by turning states into first-class polymorphic objects:

The entity aggregate delegates all state-dependent actions directly to its current state object: self._state.approve(self). Illegal transitions are naturally rejected by base state class defaults without a single conditional if check!

from __future__ import annotations
from abc import ABC, abstractmethod
from collections import defaultdict
from typing import Any, Callable, Dict, List, Optional, Self

from entityforge.core.entity import BaseEntity, EntityIdentity
from entityforge.core.value_object import MonetaryAmount
from entityforge.core.aggregate import OrderAggregate, Customer
from entityforge.core.execution import TransactionScopeGuard


# ==============================================================================
# 1. Observer Pattern: Decoupled Domain Event Bus
# ==============================================================================
class DomainEventBus:
    """
    CENTRAL PUBLISH-SUBSCRIBE EVENT BUS:
    Decouples side effects (notifications, audit logs, metrics) from business workflows.
    """
    def __init__(self) -> None:
        self._subscribers: Dict[str, List[Callable[[Dict[str, Any]], None]]] = defaultdict(list)
        self.published_events: List[Dict[str, Any]] = []

    def subscribe(self, event_type: str, handler: Callable[[Dict[str, Any]], None]) -> None:
        """Subscribes a callable handler to a specific domain event topic."""
        self._subscribers[event_type].append(handler)

    def publish(self, event_type: str, payload: Dict[str, Any]) -> None:
        """Dispatches event to all registered observers."""
        event_record = {"type": event_type, "payload": payload}
        self.published_events.append(event_record)
        for handler in self._subscribers[event_type]:
            handler(payload)


# ==============================================================================
# 2. State Pattern: Polymorphic Lifecycle State Machine
# ==============================================================================
class WorkflowState(ABC):
    """Abstract base state defining permissible domain transitions."""
    @property
    @abstractmethod
    def name(self) -> str: ...

    def submit(self, context: "OrderWorkflowContext") -> None:
        raise RuntimeError(f"Cannot submit order while in state '{self.name}'.")

    def approve(self, context: "OrderWorkflowContext") -> None:
        raise RuntimeError(f"Cannot approve order while in state '{self.name}'.")

    def cancel(self, context: "OrderWorkflowContext") -> None:
        raise RuntimeError(f"Cannot cancel order while in state '{self.name}'.")


class DraftState(WorkflowState):
    @property
    def name(self) -> str: return "DRAFT"

    def submit(self, context: "OrderWorkflowContext") -> None:
        context.transition_to(PendingState())

    def cancel(self, context: "OrderWorkflowContext") -> None:
        context.transition_to(CancelledState())


class PendingState(WorkflowState):
    @property
    def name(self) -> str: return "PENDING"

    def approve(self, context: "OrderWorkflowContext") -> None:
        context.transition_to(ApprovedState())

    def cancel(self, context: "OrderWorkflowContext") -> None:
        context.transition_to(CancelledState())


class ApprovedState(WorkflowState):
    @property
    def name(self) -> str: return "APPROVED"


class CancelledState(WorkflowState):
    @property
    def name(self) -> str: return "CANCELLED"


# ==============================================================================
# 3. Aggregate Context Integrating State Machine & Event Bus
# ==============================================================================
class OrderWorkflowContext:
    """Maintains active state machine lifecycle and dispatches domain events."""
    def __init__(self, order: OrderAggregate, event_bus: DomainEventBus) -> None:
        self.order: OrderAggregate = order
        self._event_bus: DomainEventBus = event_bus
        self._state: WorkflowState = DraftState()

    @property
    def current_state_name(self) -> str:
        return self._state.name

    def transition_to(self, new_state: WorkflowState) -> None:
        """Executes state transition and broadcasts domain event."""
        old_state_name = self._state.name
        self._state = new_state
        self._event_bus.publish(
            event_type="ORDER_STATE_CHANGED",
            payload={"order_id": str(self.order.id), "old_state": old_state_name, "new_state": new_state.name}
        )

    def submit(self) -> None: self._state.submit(self)
    def approve(self) -> None: self._state.approve(self)
    def cancel(self) -> None: self._state.cancel(self)


# ==============================================================================
# 4. Builder Pattern: Fluent Aggregate Construction
# ==============================================================================
class OrderAggregateBuilder:
    """
    CREATIONAL BUILDER PATTERN:
    Constructs an OrderAggregate step-by-step, validating invariants
    before finalizing the composed object graph.
    """
    def __init__(self) -> None:
        self._customer: Optional[Customer] = None
        self._currency: str = "USD"
        self._lines: List[tuple[str, MonetaryAmount, int]] = []

    def for_customer(self, customer: Customer) -> Self:
        self._customer = customer
        return self

    def in_currency(self, currency: str) -> Self:
        self._currency = currency
        return self

    def add_item(self, product_sku: str, unit_price: MonetaryAmount, quantity: int = 1) -> Self:
        self._lines.append((product_sku, unit_price, quantity))
        return self

    def build(self) -> OrderAggregate:
        """Finalizes validation and instantiates the composed aggregate root."""
        if not self._customer:
            raise ValueError("Cannot build OrderAggregate without a valid Customer.")
        if not self._lines:
            raise ValueError("Cannot build an empty OrderAggregate with zero line items.")

        order_id = EntityIdentity.generate()
        order = OrderAggregate(entity_id=order_id, customer=self._customer, currency=self._currency)
        for sku, price, qty in self._lines:
            order.add_line(sku, price, qty)
        return order


# ==============================================================================
# 5. Capstone Engine Coordinator
# ==============================================================================
class EntityForgeEngine:
    """
    MASTER CAPSTONE WORKFLOW ENGINE:
    Coordinates aggregate lifecycles, state machine transitions, event dispatches,
    and rollback guards into a unified enterprise interface.
    """
    def __init__(self) -> None:
        self.event_bus = DomainEventBus()
        self._in_memory_state: Dict[str, Any] = {}
        self.active_workflows: Dict[str, OrderWorkflowContext] = {}

    def create_order_builder(self) -> OrderAggregateBuilder:
        """Factory method exposing the fluent aggregate builder."""
        return OrderAggregateBuilder()

    def start_order_workflow(self, order: OrderAggregate) -> OrderWorkflowContext:
        """Registers and initializes an order workflow state machine."""
        context = OrderWorkflowContext(order=order, event_bus=self.event_bus)
        self.active_workflows[str(order.id)] = context
        self.event_bus.publish("ORDER_INITIALIZED", {"order_id": str(order.id)})
        return context

    def execute_guarded_mutation(self, mutation_callback: Callable[[Dict[str, Any]], None]) -> None:
        """
        Executes business mutations wrapped inside TransactionScopeGuard (Ch 07),
        guaranteeing full state rollback on mid-flight failure.
        """
        with TransactionScopeGuard(self._in_memory_state):
            mutation_callback(self._in_memory_state)

import pytest
from entityforge.core.entity import EntityIdentity
from entityforge.core.value_object import MonetaryAmount
from entityforge.core.aggregate import Customer
from entityforge.engine import EntityForgeEngine


class TestCapstoneWorkflowEngine:
    """End-to-End integration test validating full system synthesis across all milestones."""

    def test_full_builder_and_state_transition_lifecycle(self):
        engine = EntityForgeEngine()
        captured_events = []

        # 1. Observer Pattern: Subscribe listener to event bus
        engine.event_bus.subscribe("ORDER_STATE_CHANGED", lambda p: captured_events.append(p))

        # 2. Builder Pattern: Fluent construction of composed OrderAggregate
        customer = Customer(entity_id=EntityIdentity.generate(), email="dev_lead@capstone.io")
        order = (
            engine.create_order_builder()
            .for_customer(customer)
            .in_currency("USD")
            .add_item("SKU-OOP-MASTERCLASS", MonetaryAmount(199.99, "USD"), quantity=1)
            .add_item("SKU-ARCHITECTURE-GUIDE", MonetaryAmount(49.99, "USD"), quantity=2)
            .build()
        )

        assert order.calculate_grand_total() == MonetaryAmount(299.97, "USD")

        # 3. State Machine Pattern: Initialize and transition through workflow
        workflow = engine.start_order_workflow(order)
        assert workflow.current_state_name == "DRAFT"

        # Transition: DRAFT -> PENDING
        workflow.submit()
        assert workflow.current_state_name == "PENDING"

        # Transition: PENDING -> APPROVED
        workflow.approve()
        assert workflow.current_state_name == "APPROVED"

        # 4. Verify Observer Event Dispatching
        assert len(captured_events) == 2
        assert captured_events[0]["new_state"] == "PENDING"
        assert captured_events[1]["new_state"] == "APPROVED"

        # 5. Illegal Transition Guard: Cannot submit or modify once approved!
        with pytest.raises(RuntimeError, match=r"Cannot submit order while in state 'APPROVED'"):
            workflow.submit()

    def test_guarded_transaction_mutation_rollback(self):
        engine = EntityForgeEngine()
        engine._in_memory_state["active_jobs"] = 5

        # Execute failing mutation: Must rollback to initial snapshot cleanly
        with pytest.raises(ZeroDivisionError):
            def broken_mutation(state):
                state["active_jobs"] = 100
                _ = 1 / 0  # Crash!

            engine.execute_guarded_mutation(broken_mutation)

        # Invariant: State was reverted by TransactionScopeGuard!
        assert engine._in_memory_state["active_jobs"] == 5
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Synchronous Event Handler Blocking

Executing slow, blocking network I/O (e.g. sending emails or calling Stripe) directly inside an observer event listener on the main thread.

Why this kills throughput: The entity state transition is paused until the email gateway responds. If the email gateway times out, the database transaction locks! Always offload heavy event handlers to asynchronous task queues (Celery/RabbitMQ).

❌ State Object Memory Leaks

Creating new state instances on every single query without reusing stateless state singletons.

Why this wastes memory: State objects that hold zero instance data (like ApprovedState) should be shared immutable singletons or Flyweights, avoiding unnecessary allocations across millions of workflows.
