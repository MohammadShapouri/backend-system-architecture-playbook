Systems Architecture

Concurrency Physics: Event Loops vs. Thread Pools vs. Multiprocessing

To scale background workloads, an architect must understand the physical constraints of the host operating system's execution models:

1. Asyncio Event Loop Single-Threaded I/O

Cooperative multitasking on a single OS thread. Sockets register with the kernel via epoll/kqueue.

• Concurrency: 50,000+ sockets/node
• Overhead: ~2KB per task
• Fatal Trap: Any blocking CPU math freezes ALL tasks!
2. OS Thread Pools Preemptive Threads

Kernel-managed OS threads. Ideal for offloading blocking legacy C drivers, file disk I/O, and DNS lookups.

• Concurrency: Hundreds per node
• Overhead: ~1MB to 8MB stack per thread
• Bound: Bound by CPU context switching
3. Multiprocessing Multi-Core CPU Bound

Forked independent OS processes. Bypasses the Python Global Interpreter Lock (GIL) completely across CPU cores.

• Use Case: Image resize, PDF rendering, ML inference
• Overhead: Separate memory space per process
• Inter-process Communication: IPC / Shared memory

Queue Physics

The Bounded Buffer Principle & Proactive Backpressure

Why Unbounded In-Memory Queues Guarantee OOM Crashes

In beginner tutorials, task queues are often declared with no size limit: asyncio.Queue() or queue.Queue() (defaults to maxsize=0, meaning infinite capacity).

In enterprise systems architecture, unbounded queues are an active production hazard.

Unbounded Queue OOM Failure vs. Bounded Queue Backpressure Defense
1. Unbounded Queue (OOM Killer Crash)
• Producers enqueue tasks at: 10,000 tasks/sec
• Workers consume at: 1,000 tasks/sec
• Deficit: +9,000 tasks/sec buffer growth in RAM!
• Result: 5M tasks pile up → 16GB RAM exhausted
✗ Linux kernel triggers OOM-killer (SIGKILL)! Total loss!
2. Bounded Queue with Backpressure (Survival)
• Queue max capacity strictly capped: maxsize = 5,000
• Buffer fills to 5,000 → BACKPRESSURE ACTIVATES
• Producer options: Block, throttle, or return HTTP 429
• Memory stays permanently locked at a safe 50MB ceiling
✓ System degrades gracefully; zero process crashes!
The Law of Flow Control:

A queue does not create processing capacity; it only absorbs temporary bursts. If the average arrival rate $\lambda_{\text{in}}$ permanently exceeds processing throughput $\mu_{\text{out}}$, no queue on earth can prevent eventual failure. Backpressure must push back on the client to reduce arrival velocity!

Worker Reliability

Delivery Semantics, Poison Pills & Dead Letter Queues (DLQ)

At-Least-Once Delivery • Crash Loops • Quarantine Isolation

1. At-Most-Once Delivery (Fire & Forget)

The message broker marks the task deleted the microsecond it is dequeued, before the worker finishes execution.

Vulnerability: If the worker pod crashes midway, the task is lost forever. Unacceptable for financial settlement.

2. At-Least-Once Delivery (Industry Standard)

The worker processes the task and sends an explicit acknowledgment (ACK). If the worker crashes, the broker redelivers the task to another worker.

Requirement: Because tasks can be executed twice upon network blips, all worker handlers must be strictly idempotent!

The Poison Pill Crash Loop & Dead Letter Quarantine Failure Mode

A Poison Pill is a corrupted or unparseable task payload (e.g. invalid JSON, division-by-zero math, or an unexpected null pointer) that crashes the worker every time it is read.

1. Worker reads task #99 → Crashes with unhandled exception!
2. Under naive At-Least-Once delivery, broker redelivers task #99 immediately to the front of the queue.
3. Worker reads task #99 again → Crashes again! The cycle repeats endlessly in a 100% CPU crash loop.
4. Result: Thousands of valid tasks behind task #99 are starved forever (Head-of-Line Blocking).

The Solution (Dead Letter Queue): Maintain an incremental retry counter. If a task fails 3 consecutive times, acknowledge it from the main queue and divert it into a quarantined Dead Letter Queue (DLQ) with forensic stack traces attached for SRE investigation. The primary pipeline never stalls!

2. Bounded Queue & Worker Engine: src/omniroute/workers/queue_engine.py Backpressure & DLQ Coordinator 
# ==============================================================================
# OmniRoute Workers - Bounded Task Queue with Backpressure & DLQ Engine
# ==============================================================================

import asyncio
import json
import logging
from dataclasses import dataclass, field
from typing import Callable, Any, Awaitable, List

logger = logging.getLogger("OmniRoute.Workers")


class BackpressureExceededError(Exception):
    """Raised when the bounded queue cannot accept tasks within the grace timeout."""
    pass


@dataclass
class TaskEnvelope:
    task_id: str
    task_type: str
    payload: dict
    retries_made: int = 0
    max_retries: int = 3


class BoundedWorkerEngine:
    """
    BOUNDED ASYNCHRONOUS WORKER ENGINE:
    1. Strictly bounded buffer capacity (maxsize) preventing OOM crashes.
    2. Proactive backpressure: Enqueue operations timeout if capacity is full.
    3. At-Least-Once delivery with automated retry counters.
    4. Poison pill quarantine into Dead Letter Queue (DLQ).
    """
    def __init__(
        self,
        max_queue_size: int = 100,
        worker_concurrency: int = 4,
        dlq_sink_fn: Optional[Callable[[TaskEnvelope, str], Awaitable[None]]] = None
    ):
        self._queue: asyncio.Queue = asyncio.Queue(maxsize=max_queue_size)
        self.worker_concurrency = worker_concurrency
        self.dlq_sink_fn = dlq_sink_fn
        self._handlers: dict[str, Callable[[dict], Awaitable[Any]]] = {}
        self._worker_tasks: List[asyncio.Task] = []
        self._running = False

    def register_handler(self, task_type: str, handler: Callable[[dict], Awaitable[Any]]) -> None:
        self._handlers[task_type] = handler

    async def enqueue(self, task: TaskEnvelope, timeout_sec: float = 0.05) -> None:
        """
        PROACTIVE BACKPRESSURE ENQUEUE:
        If queue is saturated, waits up to timeout_sec. If still full, rejects request!
        """
        try:
            await asyncio.wait_for(self._queue.put(task), timeout=timeout_sec)
        except asyncio.TimeoutError:
            raise BackpressureExceededError(
                f"Worker queue capacity ({self._queue.maxsize}) exceeded. Backpressure activated."
            )

    async def start_workers(self) -> None:
        self._running = True
        for i in range(self.worker_concurrency):
            t = asyncio.create_task(self._worker_loop(f"worker-{i}"))
            self._worker_tasks.append(t)
        logger.info(f"Started {self.worker_concurrency} async workers.")

    async def stop_workers(self) -> None:
        self._running = False
        for t in self._worker_tasks:
            t.cancel()
        await asyncio.gather(*self._worker_tasks, return_exceptions=True)
        self._worker_tasks.clear()

    async def _worker_loop(self, worker_name: str) -> None:
        while self._running:
            try:
                task: TaskEnvelope = await self._queue.get()
            except asyncio.CancelledError:
                break

            handler = self._handlers.get(task.task_type)
            if not handler:
                logger.error(f"No handler registered for {task.task_type}.")
                self._queue.task_done()
                continue

            try:
                # Process task with timeout
                await asyncio.wait_for(handler(task.payload), timeout=2.0)
                self._queue.task_done()
            except Exception as exc:
                task.retries_made += 1
                logger.warning(f"Task {task.task_id} failed attempt {task.retries_made}: {str(exc)}")

                if task.retries_made >= task.max_retries:
                    # POISON PILL: Divert to Dead Letter Queue (DLQ)
                    logger.error(f"Task {task.task_id} exceeded max retries. Diverting to DLQ.")
                    if self.dlq_sink_fn:
                        await self.dlq_sink_fn(task, str(exc))
                    self._queue.task_done()
                else:
                    # Re-enqueue for retry
                    self._queue.task_done()
                    await self._queue.put(task)
3. Task Intake & DLQ Inspection Router: src/omniroute/workers/router.py FastAPI & Backpressure Control 
import json
import uuid
from fastapi import APIRouter, Depends, status, HTTPException
from pydantic import BaseModel
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select
from typing import AsyncGenerator

from omniroute.workers.queue_engine import (
    BoundedWorkerEngine, TaskEnvelope, BackpressureExceededError
)
from omniroute.workers.models import DeadLetterTaskModel

router = APIRouter(prefix="/api/v1/tasks", tags=["Async Task Processing"])


class EnqueueTaskRequestDTO(BaseModel):
    task_type: str
    payload: dict


def get_worker_engine() -> BoundedWorkerEngine:
    raise NotImplementedError

async def get_session() -> AsyncGenerator[AsyncSession, None]:
    raise NotImplementedError


@router.post(
    "/enqueue",
    status_code=status.HTTP_202_ACCEPTED,
    summary="Enqueue Background Task with Proactive Backpressure"
)
async def enqueue_background_task(
    dto: EnqueueTaskRequestDTO,
    engine: BoundedWorkerEngine = Depends(get_worker_engine)
):
    task = TaskEnvelope(
        task_id=f"task_{uuid.uuid4().hex[:10]}",
        task_type=dto.task_type,
        payload=dto.payload
    )

    try:
        await engine.enqueue(task)
    except BackpressureExceededError as exc:
        # Backpressure triggered → Fail fast with HTTP 429 Too Many Requests
        raise HTTPException(
            status_code=status.HTTP_429_TOO_MANY_REQUESTS,
            detail=str(exc)
        )

    return {"status": "ACCEPTED", "task_id": task.task_id}


@router.get("/dlq", status_code=status.HTTP_200_OK)
async def inspect_dead_letter_queue(db: AsyncSession = Depends(get_session)):
    """SRE Inspection Endpoint: Queries quarantined poison pill tasks."""
    stmt = select(DeadLetterTaskModel).order_by(DeadLetterTaskModel.quarantined_at.desc()).limit(20)
    res = await db.execute(stmt)
    tasks = res.scalars().all()
    return [
        {
            "id": t.id,
            "task_type": t.task_type,
            "failure_reason": t.failure_reason,
            "attempts": t.attempts_made,
            "quarantined_at": t.quarantined_at
        }
        for t in tasks
    ]

import asyncio
import pytest
import pytest_asyncio

from omniroute.workers.queue_engine import (
    BoundedWorkerEngine, TaskEnvelope, BackpressureExceededError
)


class TestAsyncWorkerEngineSuite:
    """Verifies bounded backpressure, task processing, and poison pill DLQ routing."""

    @pytest.mark.asyncio
    async def test_bounded_queue_enforces_backpressure_rejection(self):
        # Bounded queue with capacity = 2
        engine = BoundedWorkerEngine(max_queue_size=2, worker_concurrency=0)

        t1 = TaskEnvelope("t1", "GENERATE_PDF", {})
        t2 = TaskEnvelope("t2", "GENERATE_PDF", {})
        t3 = TaskEnvelope("t3", "GENERATE_PDF", {})

        # Enqueue first 2 tasks successfully
        await engine.enqueue(t1)
        await engine.enqueue(t2)

        # 3rd task MUST trigger BackpressureExceededError
        with pytest.raises(BackpressureExceededError, match="capacity (2) exceeded"):
            await engine.enqueue(t3, timeout_sec=0.02)

    @pytest.mark.asyncio
    async def test_worker_successfully_processes_task(self):
        processed_tasks = []

        async def mock_pdf_handler(payload: dict):
            processed_tasks.append(payload["trip_id"])

        engine = BoundedWorkerEngine(max_queue_size=10, worker_concurrency=1)
        engine.register_handler("GENERATE_PDF", mock_pdf_handler)

        await engine.start_workers()

        task = TaskEnvelope("t_99", "GENERATE_PDF", {"trip_id": "trip_12345"})
        await engine.enqueue(task)

        # Wait briefly for worker task pickup
        await asyncio.sleep(0.05)
        await engine.stop_workers()

        assert processed_tasks == ["trip_12345"]

    @pytest.mark.asyncio
    async def test_poison_pill_diverted_to_dead_letter_queue(self):
        quarantined_tasks = []

        async def mock_dlq_sink(task: TaskEnvelope, error: str):
            quarantined_tasks.append((task.task_id, error))

        async def crashing_poison_handler(payload: dict):
            raise ZeroDivisionError("Poison Pill Payload Corrupted")

        engine = BoundedWorkerEngine(max_queue_size=10, worker_concurrency=1, dlq_sink_fn=mock_dlq_sink)
        engine.register_handler("CORRUPTED_TASK", crashing_poison_handler)

        await engine.start_workers()

        poison_task = TaskEnvelope(
            task_id="poison_1",
            task_type="CORRUPTED_TASK",
            payload={},
            max_retries=3
        )
        await engine.enqueue(poison_task)

        # Wait for 3 retry attempts to exhaust
        await asyncio.sleep(0.15)
        await engine.stop_workers()

        assert len(quarantined_tasks) == 1
        assert quarantined_tasks[0][0] == "poison_1"
        assert "Poison Pill Payload Corrupted" in quarantined_tasks[0][1]
Warning Track

Beginner Pitfalls & Queue Anti-Patterns

❌ Blocking the Asyncio Event Loop in Workers

Writing time.sleep(5) or executing heavy CPU cryptographic hashing directly inside an async def task handler.

Why this freezes the entire worker process: The Asyncio event loop is cooperative and runs on a single thread. When one task blocks the thread for 5 seconds, zero other tasks can run, socket heartbeats fail, and health-check probes timeout! Always offload blocking CPU or synchronous I/O work to a thread pool via loop.run_in_executor().

❌ Infinite Retries Without Dead Letter Queues

Configuring message brokers (RabbitMQ/Celery) to automatically redeliver failed tasks infinitely without an upper retry bound.

Why this causes Head-of-Line blocking: A single poison pill payload crashes the worker, gets redelivered, crashes it again, and consumes 100% of CPU cycles in an infinite crash loop. Valid business tasks queued behind the poison pill are starved forever. Always bound retries (max 3 attempts) and divert failures to a Dead Letter Queue!
