Evolutionary Architecture

The Architectural Continuum: Monolith vs. Modular Monolith vs. Microservices

In industry discourse, architecture is frequently framed as a binary dogma: "Monoliths are legacy and bad; Microservices are modern and good." This perspective has killed hundreds of startups and burned millions in engineering capital.

Martin Fowler codified the MonolithFirst Law: "Almost all successful microservice stories started with a monolith that got too big and was broken up. Almost all cases where an architecture started directly as microservices ended up in serious trouble."

1. Spaghetti Monolith Unconstrained

Single codebase where everything imports everything. Controllers query database tables directly, bypassing domain logic.

• Fast initial velocity for 1 to 5 engineers
• Degrades into a fragile "Big Ball of Mud"
• A bug in invoice PDF generation crashes live ride dispatching!
2. Modular Monolith The Staff Sweet Spot

Single deployable artifact, but with **strictly enforced code boundaries** (DDD Bounded Contexts).

• In-process function calls: Nanosecond latency!
• Single database deployment: Simple operations
✓ Modules communicate ONLY via public interfaces!
3. Microservices Independent Deploys

Services deployed as independent network processes, each with its private database.

• Independent team scaling (100+ engineers)
• The Microservice Premium: Network latency, distributed transactions, tracing complexity

💡 The Real-World Metaphor (Plain English)

Imagine the difference between a multi-room house versus an entire suburban village of detached buildings.

A Modular Monolith is a well-designed luxury house. The kitchen, bedrooms, and bathrooms are separated by solid walls and locked doors (Module Boundaries). If someone is cooking in the kitchen, they don't disturb the person sleeping in the bedroom. But when you need an apple from the fridge, you walk down the hall in 5 seconds (In-Process Call).

A Microservice Architecture is a village where every room is a separate house 500 meters apart. Your kitchen is at 100 Main Street; your toilet is at 450 Oak Avenue; your bed is at 800 Pine Road. Every time you need a glass of water, you must put on your boots, start your car, drive across town through traffic lights (Network Latency), pay a toll bridge (Serialization/TLS), and hope the road isn't closed (Network Failure)! You only build a village when you have 500 distinct people who cannot fit inside one house.

Migration Pattern

The Strangler Fig Pattern: Zero-Downtime System Replacement

Martin Fowler (2004) • Incremental Decomposition • Zero Big-Bang Risk

During a vacation in Australia, Martin Fowler observed the biological lifecycle of the Strangler Fig: A bird drops a seed into the high branches of a massive, ancient host tree. The strangler fig germinates in the upper canopy and gradually sends aerial roots down the trunk to the forest floor. Over decades, the strangler's roots thicken into a lattice that completely envelops the host tree. Eventually, the original host tree dies and rots away inside, leaving a hollow, free-standing, flourishing strangler fig tree.

The 4 Phases of Strangler Fig Architectural Replacement
Phase 1: Intercept
Deploy Ingress Proxy (Facade) in front of legacy monolith. 100% of traffic routes to monolith.
Phase 2: Transform
Extract single domain (e.g. Dispatch Engine) into new modern service with own DB.
Phase 3: Coexist
Proxy routes 5% → 50% → 100% of dispatch traffic to new service. Shadow reads verify parity.
Phase 4: Eliminate
Decommission legacy code and drop old tables. Monolith successfully strangled!
Why the Big-Bang Rewrite is Suicide:

The "Big-Bang" approach (halting feature work for 18 months to rewrite the system from scratch) almost always ends in disaster (e.g. Netscape 6.0). The legacy system continues evolving to serve business needs; the rewrite team aims at a moving target, runs out of budget, and ships a buggy release that customers reject. The Strangler Fig delivers incremental value in production every single sprint!

Database Engineering

Splitting the Shared Database Without Dropping Queries

Dual-Writes • Backfilling • Shadow Verification • The Master Cutover

Splitting code is easy; **splitting state is hard**. In monolithic systems, tables are linked via foreign keys and complex joins. Decomposing a shared monolithic database into isolated microservice databases requires a strict 5-stage migration sequence:

Stage Write Target Read Target Safety & Rollback Mechanism
1. Dual-Write Ingress Primary: Legacy DB
Secondary: Modern DB (async outbox / CDC)		 Legacy DB (100%) If modern write fails, legacy transaction still succeeds. Zero user impact.
2. Historical Backfill Dual-Writing continues Legacy DB (100%) Background workers copy historical rows created before dual-writing started.
3. Shadow Reads (Parity Audit) Dual-Writing continues Primary Read: Legacy DB
Shadow Read: Modern DB		 Application reads both, serves legacy response, but logs diff anomalies asynchronously!
4. Canary Cutover Primary: Modern DB
Reverse Sync: Legacy DB		 Modern DB (1% → 10% → 100%) Reverse sync allows instantaneous 1-second rollback if new service misbehaves.
5. Deprecation & Pruning Modern DB exclusively Modern DB exclusively Remove reverse sync, delete legacy columns, decommission old tables.

import datetime
import uuid
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import String, Float, DateTime, Boolean


class Base(DeclarativeBase):
    pass


class LegacyMonolithicDispatchModel(Base):
    """
    THE LEGACY HOST SCHEMA (Being Strangled):
    Monolithic table coupling dispatch, vehicle coordinates, and pricing into one wide table.
    """
    __tablename__ = "legacy_monolith_dispatches"

    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
    trip_id: Mapped[str] = mapped_column(String(50), unique=True, index=True, nullable=False)
    driver_id: Mapped[str] = mapped_column(String(50), nullable=False)
    raw_status: Mapped[str] = mapped_column(String(30), default="PENDING_DISPATCH")
    fare: Mapped[float] = mapped_column(Float, nullable=False)
    created_at: Mapped[datetime.datetime] = mapped_column(DateTime, default=datetime.datetime.utcnow)


class ModernExtractedDispatchModel(Base):
    """
    THE NEW MICROSERVICE SCHEMA (The Strangler Fig):
    Normalized, decoupled domain entity optimized for high-throughput dispatch.
    """
    __tablename__ = "modern_extracted_dispatches"

    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
    trip_id: Mapped[str] = mapped_column(String(50), unique=True, index=True, nullable=False)
    assigned_driver_id: Mapped[str] = mapped_column(String(50), nullable=False)
    normalized_status: Mapped[str] = mapped_column(String(30), default="ASSIGNED")
    total_amount: Mapped[float] = mapped_column(Float, nullable=False)
    migrated_at: Mapped[datetime.datetime] = mapped_column(DateTime, default=datetime.datetime.utcnow)


class MigrationParityAuditModel(Base):
    """Logs shadow read discrepancies between legacy and modern backends."""
    __tablename__ = "migration_parity_audits"

    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
    trip_id: Mapped[str] = mapped_column(String(50), nullable=False)
    has_discrepancy: Mapped[bool] = mapped_column(Boolean, default=False)
    legacy_response_json: Mapped[str] = mapped_column(String, nullable=False)
    modern_response_json: Mapped[str] = mapped_column(String, nullable=False)
    audited_at: Mapped[datetime.datetime] = mapped_column(DateTime, default=datetime.datetime.utcnow)
2. Strangler Routing & Shadow Verifier: src/omniroute/migration/strangler_proxy.py Canary & Parity Engine 
# ==============================================================================
# OmniRoute Migration - Strangler Fig Proxy & Shadow Read Verifier
# ==============================================================================

import random
import json
import asyncio
from typing import Tuple, Dict, Any, Optional
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select

from omniroute.migration.models import (
    LegacyMonolithicDispatchModel, ModernExtractedDispatchModel, MigrationParityAuditModel
)


class StranglerRoutingEngine:
    """
    STRANGLER FIG ROUTING PROXY:
    1. Canary Routing: Routes traffic between Legacy Monolith and New Service based on migration percentage.
    2. Shadow Reads: Compares responses asynchronously without blocking client latency.
    3. Emergency Fallback: If modern service misbehaves, traffic instantly falls back to monolith.
    """
    def __init__(self, migration_traffic_percentage: float = 0.0):
        self.migration_percentage = migration_traffic_percentage  # 0.0 to 100.0
        self._lock = asyncio.Lock()

    def should_route_to_modern(self, trip_id: str) -> bool:
        """Deterministic routing based on canary percentage."""
        if self.migration_percentage <= 0.0:
            return False
        if self.migration_percentage >= 100.0:
            return True
        # Uniform hash bucket evaluation
        bucket = hash(trip_id) % 100
        return bucket < self.migration_percentage

    async def execute_dual_write(
        self, trip_id: str, driver_id: str, fare: float, session: AsyncSession
    ) -> None:
        """Stage 1: Writes to both legacy and modern tables within transaction."""
        legacy = LegacyMonolithicDispatchModel(
            trip_id=trip_id,
            driver_id=driver_id,
            fare=fare,
            raw_status="PENDING_DISPATCH"
        )
        modern = ModernExtractedDispatchModel(
            trip_id=trip_id,
            assigned_driver_id=driver_id,
            total_amount=fare,
            normalized_status="ASSIGNED"
        )
        session.add(legacy)
        session.add(modern)
        await session.commit()

    async def get_dispatch_with_shadow_parity(
        self, trip_id: str, session: AsyncSession
    ) -> Tuple[Dict[str, Any], str]:
        """
        Reads from active target and executes asynchronous shadow comparison.
        """
        use_modern = self.should_route_to_modern(trip_id)

        # Fetch both to verify parity
        legacy_stmt = select(LegacyMonolithicDispatchModel).where(LegacyMonolithicDispatchModel.trip_id == trip_id)
        modern_stmt = select(ModernExtractedDispatchModel).where(ModernExtractedDispatchModel.trip_id == trip_id)

        leg_res = await session.execute(legacy_stmt)
        mod_res = await session.execute(modern_stmt)

        legacy_row = leg_res.scalar_one_or_none()
        modern_row = mod_res.scalar_one_or_none()

        legacy_dict = {"driver": legacy_row.driver_id, "fare": legacy_row.fare} if legacy_row else {}
        modern_dict = {"driver": modern_row.assigned_driver_id, "fare": modern_row.total_amount} if modern_row else {}

        # Parity Check
        has_diff = legacy_dict != modern_dict
        audit = MigrationParityAuditModel(
            trip_id=trip_id,
            has_discrepancy=has_diff,
            legacy_response_json=json.dumps(legacy_dict),
            modern_response_json=json.dumps(modern_dict)
        )
        session.add(audit)
        await session.commit()

        if use_modern and modern_row:
            return modern_dict, "MODERN_MICROSERVICE"
        return legacy_dict, "LEGACY_MONOLITH"
3. Strangler Ingress API Router: src/omniroute/migration/router.py FastAPI & Canary Ingress 
from fastapi import APIRouter, Depends, status, HTTPException
from pydantic import BaseModel, Field
from sqlalchemy.ext.asyncio import AsyncSession
from typing import AsyncGenerator

from omniroute.migration.strangler_proxy import StranglerRoutingEngine

router = APIRouter(prefix="/api/v1/migration", tags=["Strangler Fig Migration"])
strangler_engine = StranglerRoutingEngine(migration_traffic_percentage=0.0)


class IngestDispatchDTO(BaseModel):
    trip_id: str
    driver_id: str
    fare: float = Field(..., gt=0.0)


class CanaryConfigDTO(BaseModel):
    percentage: float = Field(..., ge=0.0, le=100.0)


async def get_session() -> AsyncGenerator[AsyncSession, None]:
    raise NotImplementedError


@router.post("/canary/configure", status_code=status.HTTP_200_OK)
async def configure_canary_percentage(dto: CanaryConfigDTO):
    strangler_engine.migration_percentage = dto.percentage
    return {"status": "UPDATED", "active_modern_percentage": dto.percentage}


@router.post("/dispatch/write", status_code=status.HTTP_201_CREATED)
async def write_dispatch(dto: IngestDispatchDTO, db: AsyncSession = Depends(get_session)):
    await strangler_engine.execute_dual_write(dto.trip_id, dto.driver_id, dto.fare, db)
    return {"status": "DUAL_WRITE_COMMITTED", "trip_id": dto.trip_id}


@router.get("/dispatch/{trip_id}", status_code=status.HTTP_200_OK)
async def read_dispatch(trip_id: str, db: AsyncSession = Depends(get_session)):
    data, served_by = await strangler_engine.get_dispatch_with_shadow_parity(trip_id, db)
    if not data:
        raise HTTPException(status_code=404, detail="Trip dispatch record not found.")
    return {"trip_id": trip_id, "served_by": served_by, "data": data}

import pytest
import pytest_asyncio
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
from sqlalchemy import select

from omniroute.migration.models import Base, MigrationParityAuditModel
from omniroute.migration.strangler_proxy import StranglerRoutingEngine


@pytest_asyncio.fixture
async def in_memory_db():
    engine = create_async_engine("sqlite+aiosqlite:///:memory:", echo=False)
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)

    session_factory = async_sessionmaker(engine, expire_on_commit=False, class_=AsyncSession)
    yield session_factory
    await engine.dispose()


class TestStranglerMigrationSuite:
    """Verifies canary routing, dual-write consistency, and shadow parity audits."""

    @pytest.mark.asyncio
    async def test_canary_routing_transitions_between_backends(self, in_memory_db):
        engine = StranglerRoutingEngine(migration_traffic_percentage=0.0)

        async with in_memory_db() as session:
            # 1. Dual-write trip
            await engine.execute_dual_write("trip_42", "driver_99", 35.0, session)

            # 2. At 0%, read MUST be served by LEGACY_MONOLITH
            data, source = await engine.get_dispatch_with_shadow_parity("trip_42", session)
            assert source == "LEGACY_MONOLITH"
            assert data["driver"] == "driver_99"

            # 3. Flip canary to 100% → MUST be served by MODERN_MICROSERVICE
            engine.migration_percentage = 100.0
            data_mod, source_mod = await engine.get_dispatch_with_shadow_parity("trip_42", session)
            assert source_mod == "MODERN_MICROSERVICE"
            assert data_mod["driver"] == "driver_99"

            # 4. Verify Shadow Audit logged zero discrepancies
            stmt = select(MigrationParityAuditModel).where(MigrationParityAuditModel.trip_id == "trip_42")
            res = await session.execute(stmt)
            audits = res.scalars().all()
            assert len(audits) == 2
            assert all(a.has_discrepancy is False for a in audits)
Warning Track

Beginner Pitfalls & Migration Anti-Patterns

❌ The "Big Bang" Rewrite Trap

Halting production feature velocity to build a brand new microservice system from scratch over 12 months.

Why this causes engineering bankruptcy: While you rewrite, the legacy monolith continues evolving to meet business emergencies. The rewrite team aims at a moving target, accumulates massive deployment risk, and eventually launches an untested monolith replacement that crashes on Day 1. Always strangle incrementally using proxy interception!

❌ The Shared Database Anti-Pattern

Extracting a new microservice code repository while pointing it directly at the legacy monolith's shared database tables.

Why this creates a Distributed Monolith: If the monolith team renames a column, the microservice crashes. If the microservice locks a row, the monolith deadlocks. You have combined the operational network overhead of microservices with the tight coupling of a monolith! Services must own private, encapsulated state.
