Part 01

Computer Science: Security CLI Architecture & The UNIX Philosophy

A common anti-pattern among backend developers is treating CLI scripts as disposable throwaway code. In production security engineering, command-line tools are the primary interface for automation scripts, Kubernetes initialization jobs, and incident response runbooks.

Following the UNIX Philosophy, a professional cryptographic CLI must fulfill three core invariants:

1. Silence is Golden

Emit only the requested output to stdout (e.g. printing only the raw token string on issue). Logging, status banners, and diagnostics belong on stderr so outputs can be piped directly into curl, jq, or shell variables.

2. Semantic Exit Codes

Never return an exit code of 0 when an error occurs! CI pipelines and bash scripts evaluate process return codes. If a token is expired or tampered with, the CLI must return distinct non-zero exit codes.

3. Least Privilege Files

When generating private cryptographic keys to disk, writing files with default world-readable permissions (0o644) exposes secrets to other local users. Keys must be created atomically with owner-only access (0o600).

Part 02

Under the Hood: Diagnostic Inspection & Key ID Discovery

When building terminal tools or complex identity gateways, you frequently encounter a "chicken-and-egg" dilemma: How do you know which public key to verify a token with before you verify the token?

In multi-tenant or rotating key ecosystems, tokens include a kid (Key ID) attribute inside their Header segment. PyJWT provides specialized low-level functions designed specifically for header inspection and diagnostic decoding:

jwt.get_unverified_header() RFC 7515 Header

Extracts and parses only the first Base64URL segment of a JWT string into a dictionary, completely ignoring the payload and signature: 

header = jwt.get_unverified_header(raw_token)
# Output: {"alg": "RS256", "typ": "JWT", "kid": "key_2026_q4"}
key_id = header.get("kid")
# Downstream services use key_id to fetch the matching public key!
options={"verify_signature": False} Diagnostic Only

Decodes the second Base64URL segment (Payload) into JSON without performing cryptographic signature math: 

unverified_claims = jwt.decode(
    raw_token, 
    options={"verify_signature": False}
)
# Ideal for CLI inspection: view 'sub' or 'exp' even on expired tokens!

Architectural Boundary Rule:

Unverified extraction is legitimate ONLY for CLI diagnostic inspection tools or extracting the kid header to resolve which public key to verify against. Never make authorization decisions (such as checking claims["role"] == "admin") on an unverified payload in application services!

Part 03

Filesystem Security: POSIX Permissions on Secret Keys

When a CLI tool generates cryptographic keypairs to disk, standard Python functions like open(path, "w") create files respecting the operating system's default umask (typically yielding 0o644 / -rw-r--r--).

In shared Linux environments (multi-tenant bastion hosts, developer workstations, shared CI runners), a world-readable private key permits any unprivileged user or malicious background daemon to read your signing credentials!

// Production Standard: Atomic File Creation with Restricted POSIX Modes
import os
from pathlib import Path

def save_private_key_securely(path: Path, pem_content: str) -> None:
    # 1. Use os.open to atomically enforce 0o600 (-rw-------) before file creation!
    # Prevents race conditions where a file exists as world-readable before chmod is applied.
    flags = os.O_WRONLY | os.O_CREAT | os.O_TRUNC
    mode = 0o600  # Strictly readable/writable ONLY by the owning user

    fd = os.open(path, flags, mode)
    with open(fd, "w", encoding="utf-8") as f:
        f.write(pem_content)

def save_public_key(path: Path, pem_content: str) -> None:
    # Public keys contain zero secret data and are safe with standard 0o644 (-rw-r--r--)
    path.write_text(pem_content, encoding="utf-8")

1. Admin Terminal Command Suite: src/tokenforge/cli/main.py Typer Operator Application 
# ==============================================================================
# TokenForge CLI - Administrative Operator Terminal (Milestone 03)
# ==============================================================================

import os
import sys
import json
import time
from pathlib import Path
from typing import Optional
import jwt
import typer

from tokenforge.core.crypto import KeyManager, TokenEngine
from tokenforge.services.validator import (
    TokenValidator, 
    TokenExpiredError, 
    TokenSecurityError, 
    AudienceMismatchError
)

cli_app = typer.Typer(name="tokenforge", help="TokenForge Cryptographic Operator Utility")

# ==============================================================================
# Command 1: Key Generation (keygen)
# ==============================================================================
@cli_app.command("keygen")
def generate_keys(
    private_out: Path = typer.Option(..., "--out-private", "-p", help="Destination path for Private Key PEM"),
    public_out: Path = typer.Option(..., "--out-public", "-u", help="Destination path for Public Key PEM"),
    bits: int = typer.Option(2048, "--bits", "-b", help="Modulus size (min 2048)")
):
    """Generates a secure RSA keypair and saves to disk with restricted permissions."""
    typer.secho(f"Generating {bits}-bit RSA Keypair...", fg=typer.colors.BLUE, err=True)
    priv_pem, pub_pem = KeyManager.generate_rsa_keypair(key_size=bits)

    # 1. Save Private Key atomically with POSIX 0o600 (Owner Read/Write ONLY)
    flags = os.O_WRONLY | os.O_CREAT | os.O_TRUNC
    fd = os.open(private_out, flags, 0o600)
    with open(fd, "w", encoding="utf-8") as f:
        f.write(priv_pem)

    # 2. Save Public Key with standard 0o644 (World Readable)
    public_out.write_text(pub_pem, encoding="utf-8")

    typer.secho(f"✓ Private Key written to: {private_out} (Mode: 0600)", fg=typer.colors.GREEN, err=True)
    typer.secho(f"✓ Public Key written to:  {public_out} (Mode: 0644)", fg=typer.colors.GREEN, err=True)


@cli_app.command("issue")
def issue_token(
    subject: str = typer.Option(..., "--sub", help="User ID / Principal"),
    audience: str = typer.Option(..., "--aud", help="Target service audience"),
    issuer: str = typer.Option("https://iam.tokenforge.internal", "--iss"),
    ttl: int = typer.Option(300, "--ttl", help="Time to live in seconds"),
    private_key_path: Path = typer.Option(..., "--key", "-k", help="Path to Private Key PEM")
):
    """Issues a signed RS256 token and prints the raw string to stdout."""
    if not private_key_path.exists():
        typer.secho(f"ERROR: Key file {private_key_path} not found.", fg=typer.colors.RED, err=True)
        raise typer.Exit(code=1)

    private_pem = private_key_path.read_text(encoding="utf-8")
    engine = TokenEngine(algorithm="RS256", signing_key=private_pem)

    now = int(time.time())
    claims = {
        "iss": issuer,
        "sub": subject,
        "aud": audience,
        "iat": now,
        "exp": now + ttl,
    }

    token = engine.issue_token(claims)
    # UNIX Standard: Emit ONLY the token string to stdout for piping
    typer.echo(token)


@cli_app.command("verify")
def verify_token(
    token: str = typer.Option(..., "--token", "-t", help="Raw JWT token string"),
    public_key_path: Path = typer.Option(..., "--key", "-k", help="Path to Public Key PEM"),
    expected_aud: str = typer.Option(..., "--aud", help="Expected audience"),
    expected_iss: str = typer.Option("https://iam.tokenforge.internal", "--iss")
):
    """
    Verifies token validity using exit codes:
    Exit 0: Valid • Exit 2: Invalid/Tampered • Exit 3: Expired
    """
    if not public_key_path.exists():
        typer.secho(f"ERROR: Key file {public_key_path} not found.", fg=typer.colors.RED, err=True)
        raise typer.Exit(code=1)

    public_pem = public_key_path.read_text(encoding="utf-8")
    validator = TokenValidator(
        verification_key=public_pem,
        expected_issuer=expected_iss,
        expected_audience=expected_aud
    )

    try:
        validated = validator.decode_and_validate(token)
        typer.secho("✓ TOKEN VALID", fg=typer.colors.GREEN, err=True)
        typer.echo(json.dumps(validated.claims, indent=2))
        raise typer.Exit(code=0)
    except TokenExpiredError as e:
        typer.secho(f"✗ REJECTED: {e}", fg=typer.colors.RED, err=True)
        raise typer.Exit(code=3)
    except TokenSecurityError as e:
        typer.secho(f"✗ REJECTED: {e}", fg=typer.colors.RED, err=True)
        raise typer.Exit(code=2)


@cli_app.command("inspect")
def inspect_token(
    token: str = typer.Option(..., "--token", "-t", help="Raw JWT string")
):
    """Dumps unverified headers and payload for incident triage and debugging."""
    try:
        header = jwt.get_unverified_header(token)
        payload = jwt.decode(token, options={"verify_signature": False})
        
        output = {
            "unverified_header": header,
            "unverified_payload": payload
        }
        typer.echo(json.dumps(output, indent=2))
    except Exception as exc:
        typer.secho(f"Failed to parse token segments: {exc}", fg=typer.colors.RED, err=True)
        raise typer.Exit(code=1)

# ==============================================================================
# TokenForge Test Suite - CLI Functional Testing (Milestone 03)
# ==============================================================================

import stat
import pytest
from typer.testing import CliRunner
from tokenforge.cli.main import cli_app

runner = CliRunner()

@pytest.mark.functional
class TestTokenForgeCLI:
    """Verifies terminal commands, exit codes, output streams, and POSIX permissions."""

    def test_full_lifecycle_keygen_issue_verify_cycle(self, tmp_path):
        priv_key = tmp_path / "id_rsa"
        pub_key = tmp_path / "id_rsa.pub"

        # 1. Test Keygen: verify files created and permissions strictly 0o600 on private key
        res_keygen = runner.invoke(cli_app, ["keygen", "-p", str(priv_key), "-u", str(pub_key)])
        assert res_keygen.exit_code == 0
        assert priv_key.exists()
        assert pub_key.exists()

        # POSIX Mode Verification: File must NOT be world-readable!
        file_mode = stat.S_IMODE(priv_key.stat().st_mode)
        assert file_mode == 0o600

        # 2. Test Issue: emits raw JWT string to stdout
        res_issue = runner.invoke(cli_app, [
            "issue",
            "--sub", "operator_01",
            "--aud", "clearing-engine",
            "--key", str(priv_key),
            "--ttl", "600"
        ])
        assert res_issue.exit_code == 0
        jwt_token = res_issue.stdout.strip()
        assert len(jwt_token.split(".")) == 3

        # 3. Test Verify: verifies valid token returns exit code 0
        res_verify = runner.invoke(cli_app, [
            "verify",
            "--token", jwt_token,
            "--key", str(pub_key),
            "--aud", "clearing-engine"
        ])
        assert res_verify.exit_code == 0
        assert "operator_01" in res_verify.stdout

    def test_verify_returns_exit_code_2_on_tampered_token(self, tmp_path):
        priv_key = tmp_path / "priv.pem"
        pub_key = tmp_path / "pub.pem"
        runner.invoke(cli_app, ["keygen", "-p", str(priv_key), "-u", str(pub_key)])
        
        res_issue = runner.invoke(cli_app, ["issue", "--sub", "alice", "--aud", "app", "--key", str(priv_key)])
        token = res_issue.stdout.strip()

        # Tamper with signature segment
        tampered = token[:-6] + "AAAAAA"

        res_verify = runner.invoke(cli_app, ["verify", "--token", tampered, "--key", str(pub_key), "--aud", "app"])
        
        # Semantic Exit Code: 2 represents cryptographic verification failure
        assert res_verify.exit_code == 2

    def test_inspect_dumps_unverified_header_and_payload(self):
        # A token signed with arbitrary payload
        sample_token = (
            "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCIsImtpZCI6InRlc3Rfa2V5In0."
            "eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkFsaWNlIFRlc3RlciIsImlhdCI6MTUxNjIzOTAyMn0."
            "SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c"
        )

        res = runner.invoke(cli_app, ["inspect", "--token", sample_token])
        assert res.exit_code == 0
        assert "test_key" in res.stdout
        assert "Alice Tester" in res.stdout
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Exit Code 0 on Cryptographic Failures

Writing except TokenSecurityError: print("Verification failed") without raising typer.Exit(code=2).

Why this causes security breaches: Automated scripts and deployment pipelines (such as bash tokenforge verify || exit 1) rely exclusively on the OS return code. If your CLI prints an error message but returns exit code 0, downstream deployment scripts assume the token is 100% authentic and deploy untrusted configuration!

❌ Printing Keys to Stdout

Writing typer.echo(f"Generated Private Key: {priv_pem}").

Why this is hazardous: Anything written to stdout in a CI runner or developer terminal is captured by centralized log aggregators (Datadog, Loki, CloudWatch), permanently leaking the authority's root signing key to anyone with log read access. Private keys must be written directly to restricted filesystem paths.
