Part 01

Computer Science: Zero-Trust Inter-Service Token Federation

When scaling from a monolithic backend to distributed microservices, engineers frequently introduce a critical architectural flaw: they configure downstream services (such as Billing, Order, or Notification Services) to make a synchronous HTTP introspection call back to the central IAM / Auth Service on every single incoming request to check if the token is valid.

This "Introspection Anti-Pattern" destroys the primary benefit of microservices: it couples all services to a single point of failure, doubles network latency on every API call, and collapses under high concurrent load.

The Federated Token Verification Pipeline

Eliminating Centralized Bottlenecks with Local Asymmetric Verification

1. Client / Consumer
2. Central IAM Service (Issuer)
3. Resource Microservice (Verifier)
Step 1: Authentication & Minting POST /api/v1/auth/token

Client presents credentials. IAM service authenticates against database, signs JWT using RSA Private Key, and returns Bearer token.

Step 2: Key Distribution (Cached) GET /.well-known/jwks.json

Resource Microservice fetches RSA Public Key once at startup (or via JWKS), caching it in memory. Private key is NEVER exposed!

Step 3: Zero-Network-Hop Verification LOCAL MEMORY CHECK (0.1ms)

Client calls Resource Service with Bearer token. Resource Service verifies signature using cached Public Key. Zero HTTP calls back to IAM!

The Federation Invariant:

If the central IAM service experiences a total cloud outage or goes offline for database maintenance, all downstream microservices continue running and validating traffic uninterrupted. Local mathematical verification requires only the static public key.

Part 02

Under the Hood: Key Lifecycle Management in lifespan

Reading PEM-encoded cryptographic keys from disk on every single incoming HTTP request inside your controller or dependency function is a severe performance bottleneck: it incurs repeated synchronous disk I/O and forces CPU-heavy RSA key parsing thousands of times per second.

The production standard is to initialize cryptographic keys exactly once during application boot using FastAPI’s modern @asynccontextmanager lifespan protocol, storing the compiled TokenEngine and TokenValidator instances on the application state:

// Loading and Caching Asymmetric Keys in app/main.py:
from contextlib import asynccontextmanager
from fastapi import FastAPI
from pathlib import Path
from tokenforge.core.crypto import TokenEngine
from tokenforge.services.validator import TokenValidator

@asynccontextmanager
async def lifespan(app: FastAPI):
    # 1. APPLICATION BOOT: Read PEM keys from environment paths ONCE
    priv_path = Path(os.getenv("JWT_PRIVATE_KEY_PATH", "certs/jwt_rs256.key"))
    pub_path = Path(os.getenv("JWT_PUBLIC_KEY_PATH", "certs/jwt_rs256.pub"))

    private_pem = priv_path.read_text(encoding="utf-8") if priv_path.exists() else None
    public_pem = pub_path.read_text(encoding="utf-8")

    # 2. Attach singletons directly to application state
    app.state.token_engine = TokenEngine(algorithm="RS256", signing_key=private_pem) if private_pem else None
    app.state.token_validator = TokenValidator(
        verification_key=public_pem,
        expected_issuer="https://iam.tokenforge.internal",
        expected_audience="vaultflow-resource-service"
    )

    yield  # Application handles incoming HTTP traffic here

    # 3. APPLICATION SHUTDOWN: Flush state
    app.state.token_engine = None
    app.state.token_validator = None
Part 03

Defensive Dependency Injection: Type-Safe Authentication Guards

In FastAPI, controllers must never write manual authorization checks like if not request.headers.get("Authorization"): .... That violates the Single Responsibility Principle and scatters security vulnerabilities across route handlers.

We encapsulate authentication inside a modular FastAPI dependency using OAuth2PasswordBearer and Python’s typing.Annotated. The dependency extracts the Bearer token, routes it through TokenValidator, maps claims to an immutable AuthenticatedPrincipal dataclass, and enforces required permission scopes before the controller executes:

Security Architecture

1. The Dependency Guard Contract

Extracts and validates cryptographic tokens, raising clean HTTP 401 Unauthorized responses with standard WWW-Authenticate headers on any failure: 

def require_authenticated_principal(
    request: Request,
    token: str = Depends(oauth2_scheme)
) -> AuthenticatedPrincipal:
    validator: TokenValidator = request.app.state.token_validator
    try:
        validated = validator.decode_and_validate(token)
        return AuthenticatedPrincipal.from_validated_token(validated)
    except TokenSecurityError as err:
        raise HTTPException(
            status_code=401, 
            detail=str(err),
            headers={"WWW-Authenticate": "Bearer"}
        )
Access Control

2. Scope-Based Authorization

Validates that the principal holds required operational permissions (e.g. "settlement:execute"), raising HTTP 403 Forbidden if scopes are insufficient: 

class RequireScopes:
    def __init__(self, *required_scopes: str):
        self.required_scopes = set(required_scopes)

    def __call__(self, principal: Principal = Depends(require_authenticated_principal)):
        if not self.required_scopes.issubset(principal.scopes):
            raise HTTPException(
                status_code=403, 
                detail="Insufficient token scopes."
            )
        return principal

# ==============================================================================
# TokenForge Web Gateway - Federated Identity & Resource APIs (Milestone 04)
# ==============================================================================

import time
from contextlib import asynccontextmanager
from dataclasses import dataclass
from typing import Annotated, Any, Dict, List, Set
from fastapi import FastAPI, Depends, HTTPException, Request, status
from fastapi.security import OAuth2PasswordBearer
from pydantic import BaseModel, Field

from tokenforge.core.crypto import TokenEngine, KeyManager
from tokenforge.services.validator import TokenValidator, ValidatedToken, TokenSecurityError

# Informs OpenAPI Swagger documentation where tokens are issued
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/auth/token")

@dataclass(frozen=True)
class AuthenticatedPrincipal:
    """Typed domain identity injected into protected route handlers."""
    subject: str
    scopes: Set[str]
    raw_claims: Dict[str, Any]

    @classmethod
    def from_validated_token(cls, token: ValidatedToken) -> "AuthenticatedPrincipal":
        raw_scope = token.claims.get("scope", "")
        parsed_scopes = set(raw_scope.split()) if isinstance(raw_scope, str) else set(raw_scope)
        return cls(
            subject=token.subject,
            scopes=parsed_scopes,
            raw_claims=token.claims
        )


# ==============================================================================
# Application Lifespan: Pre-loads RSA Keys into RAM
# ==============================================================================
@asynccontextmanager
async def lifespan(app: FastAPI):
    # For demonstration, generate keys on boot (in production, read from certs/ or KMS)
    priv_pem, pub_pem = KeyManager.generate_rsa_keypair(key_size=2048)

    # Attach cryptographic singletons directly to application state
    app.state.token_engine = TokenEngine(algorithm="RS256", signing_key=priv_pem)
    app.state.token_validator = TokenValidator(
        verification_key=pub_pem,
        expected_issuer="https://iam.tokenforge.internal",
        expected_audience="clearing-engine-service",
        allowed_algorithms=["RS256"]
    )
    app.state.public_key_pem = pub_pem

    yield

    app.state.token_engine = None
    app.state.token_validator = None

app = FastAPI(title="TokenForge Gateway API", version="1.0.0", lifespan=lifespan)


# ==============================================================================
# Security Dependencies

def get_current_principal(
    request: Request,
    token: Annotated[str, Depends(oauth2_scheme)]
) -> AuthenticatedPrincipal:
    """
    ZERO-NETWORK-HOP VALIDATION:
    Verifies Bearer token locally in-memory using public key.
    Zero network latency back to IAM authority!
    """
    validator: TokenValidator = request.app.state.token_validator
    try:
        validated = validator.decode_and_validate(token)
        return AuthenticatedPrincipal.from_validated_token(validated)
    except TokenSecurityError as err:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail=str(err),
            headers={"WWW-Authenticate": "Bearer"}
        )


class RequireScopes:
    """Defensive parameterizable authorization guard checking token scope claims."""
    def __init__(self, *required_scopes: str):
        self.required_scopes = set(required_scopes)

    def __call__(
        self,
        principal: Annotated[AuthenticatedPrincipal, Depends(get_current_principal)]
    ) -> AuthenticatedPrincipal:
        if not self.required_scopes.issubset(principal.scopes):
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail=f"Insufficient token scopes. Requires: {sorted(list(self.required_scopes))}"
            )
        return principal

# Endpoint Schemas
# ==============================================================================
class TokenIssueRequest(BaseModel):
    username: str = Field(..., examples=["operator_alice"])
    audience: str = Field(..., examples=["clearing-engine-service"])
    scopes: List[str] = Field(default_factory=list, examples=[["settlement:execute", "ledger:read"]])

class TokenResponse(BaseModel):
    access_token: str
    token_type: str = "bearer"
    expires_in: int


# ==============================================================================
# IAM Authority Endpoints (Issuance & Public Key Discovery)
# ==============================================================================
@app.post("/api/v1/auth/token", response_model=TokenResponse, status_code=status.HTTP_201_CREATED, tags=["IAM Authority"])
async def issue_access_token(payload: TokenIssueRequest, request: Request):
    """IAM Authority endpoint: Mints RS256 token using Private Key."""
    engine: TokenEngine = request.app.state.token_engine
    now = int(time.time())
    ttl = 900  # 15 minutes

    claims = {
        "iss": "https://iam.tokenforge.internal",
        "sub": payload.username,
        "aud": payload.audience,
        "iat": now,
        "exp": now + ttl,
        "scope": " ".join(payload.scopes)
    }

    token = engine.issue_token(claims)
    return TokenResponse(access_token=token, expires_in=ttl)


@app.get("/.well-known/public-key.pem", tags=["Key Distribution"])
async def get_public_key(request: Request):
    """Public key discovery endpoint for downstream microservice caching."""
    return {"algorithm": "RS256", "public_key": request.app.state.public_key_pem}


# ==============================================================================
# Resource Microservice Endpoints (Protected by Local Verification Guard)
# ==============================================================================
@app.post("/api/v1/settlements/execute", tags=["Resource Service"])
async def execute_financial_settlement(
    principal: Annotated[AuthenticatedPrincipal, Depends(RequireScopes("settlement:execute"))]
):
    """Protected resource route: Enforces both local RS256 validity AND required scope."""
    return {
        "status": "EXECUTED",
        "operator": principal.subject,
        "authorized_scopes": sorted(list(principal.scopes))
    }

@pytest.mark.asyncio
class TestFederatedWebGateway:
    """Integration tests asserting issuance, verification, scopes, and attack defense."""

    async def test_full_issuance_and_local_resource_access_cycle(self, client: httpx.AsyncClient):
        # 1. Authenticate with IAM and acquire RS256 token
        issue_res = await client.post(
            "/api/v1/auth/token",
            json={
                "username": "bank_operator_01",
                "audience": "clearing-engine-service",
                "scopes": ["settlement:execute", "ledger:read"]
            }
        )
        assert issue_res.status_code == 201
        token = issue_res.json()["access_token"]

        # 2. Access protected resource microservice using the Bearer token
        resource_res = await client.post(
            "/api/v1/settlements/execute",
            headers={"Authorization": f"Bearer {token}"}
        )
        assert resource_res.status_code == 200
        data = resource_res.json()
        assert data["status"] == "EXECUTED"
        assert data["operator"] == "bank_operator_01"

    async def test_insufficient_scopes_returns_403_forbidden(self, client: httpx.AsyncClient):
        # Issue token lacking the mandatory 'settlement:execute' scope
        issue_res = await client.post(
            "/api/v1/auth/token",
            json={
                "username": "auditor_bob",
                "audience": "clearing-engine-service",
                "scopes": ["reports:read"]  # Missing settlement:execute
            }
        )
        token = issue_res.json()["access_token"]

        res = await client.post(
            "/api/v1/settlements/execute",
            headers={"Authorization": f"Bearer {token}"}
        )
        assert res.status_code == 403
        assert "Insufficient token scopes" in res.json()["detail"]

    async def test_audience_mismatch_returns_401_unauthorized(self, client: httpx.AsyncClient):
        # Issue token intended for 'analytics-service', NOT 'clearing-engine-service'
        issue_res = await client.post(
            "/api/v1/auth/token",
            json={
                "username": "alice",
                "audience": "analytics-service",
                "scopes": ["settlement:execute"]
            }
        )
        token = issue_res.json()["access_token"]

        res = await client.post(
            "/api/v1/settlements/execute",
            headers={"Authorization": f"Bearer {token}"}
        )
        assert res.status_code == 401
        assert "Audience mismatch" in res.json()["detail"]
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Synchronous Introspection Callbacks

Writing await httpx.post("http://iam-service/verify", json={"token": token}) inside microservice route guards.

Why this destroys microservice performance: It introduces a synchronous network hop on 100% of API calls, doubles your latency budget, and creates a distributed bottleneck where an IAM blip knocks down all downstream services. Fix: Distribute the static public key via /.well-known/public-key.pem and verify tokens locally in memory using PyJWT!

❌ Disk Reads Inside Route Dependencies

Writing open("certs/jwt.pub").read() inside a FastAPI Depends() function.

Why this thrashes CPU & Disk: If your API handles 2,000 requests per second, you are reading the file from the OS filesystem 2,000 times per second and reparsing RSA prime factors 2,000 times. Fix: Load the public key into memory once during application startup inside @asynccontextmanager lifespan!
