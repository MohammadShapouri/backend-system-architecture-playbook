Part 01

Computer Science: The BST Invariant & Pathological Degeneration

A Binary Search Tree (BST) is a node-based binary tree data structure where each node stores a key, associated payload data, and left and right child pointers. The structure is governed by the Binary Search Invariant:

• For any given node N:
    All keys in the left subtree of N must be strictly LESS THAN N.key.
    All keys in the right subtree of N must be strictly GREATER THAN N.key.

When keys are inserted in random order, a naive BST forms a balanced branching tree with height $h \approx \log_2 n$, providing $O(\log n)$ average search times.

However, database applications frequently ingest monotonically increasing data (such as auto-incrementing primary IDs, timestamps, or sequential invoice numbers). When sorted data is inserted into a naive BST, every new node is appended exclusively as the right child of the previous node. The tree pathologically degenerates into a singly linked list!

Part 02

Under the Hood: The AVL Invariant & The Four Rotation Cases

Invented in 1962 by Soviet mathematicians Georgy Adelson-Velsky and Evgenii Landis, the AVL Tree was the world's first dynamically self-balancing binary search tree.

Every node in an AVL tree maintains a cached height property (where a leaf node has $\text{height} = 1$, and an empty child has $\text{height} = 0$). The Balance Factor ($\text{BF}$) of any node $N$ is defined mathematically as:

Balance Factor(N) = height(N.left) - height(N.right)

The AVL Invariant: In a valid AVL tree, every node must maintain $\text{BF}(N) \in \{-1, 0, 1\}$. If an insertion or deletion causes $|\text{BF}(N)| > 1$, the tree is strictly unbalanced. Balance is restored in $O(1)$ time using Tree Rotations.

1. Left-Left Case → Single Right Rotation BF = +2, Child BF ≥ 0

Occurs when a node is inserted into the left subtree of the left child. Restored by pulling the left child up and rotating the unbalanced parent down to the right. 

      y (BF=+2)                x
     / \                      / \
    x   T3   -- Right Rot --> T1  y
   / \                           / \
  T1  T2                        T2  T3
2. Right-Right Case → Single Left Rotation BF = -2, Child BF ≤ 0

Occurs when a node is inserted into the right subtree of the right child. Restored by pulling the right child up and rotating the parent down to the left. 

    x (BF=-2)                  y
   / \                        / \
  T1  y      -- Left Rot --> x   T3
     / \                    / \
    T2  T3                 T1  T2
3. Left-Right Case → Double (Left + Right) BF = +2, Child BF < 0

Insertion occurred in the inner right subtree of the left child. Step 1: Left-rotate the left child to convert to an LL shape. Step 2: Right-rotate the unbalanced parent. 

    z (+2)         z (+2)
   /              /             x
  y (-1)  →      x       →    / \
   \            /            y   z
    x          y
4. Right-Left Case → Double (Right + Left) BF = -2, Child BF > 0

Insertion occurred in the inner left subtree of the right child. Step 1: Right-rotate the right child to convert to an RR shape. Step 2: Left-rotate the unbalanced parent. 

  x (-2)         x (-2)
   \              \             y
    z (+1) →      y      →    / \
   /                \        x   z
  y                  z
Part 03

Algorithmic Mechanics: Depth-First vs. Breadth-First Traversals

Traversing a non-linear tree involves visiting every node in a deterministic order. Four canonical traversal algorithms govern systems engineering:

1. In-Order (Left → Node → Right) Strictly Sorted

Recursively traverses the left subtree, visits the node, then traverses the right subtree. The Mathematical Invariant: In any valid BST, an in-order traversal yields keys in strictly ascending sorted order! Eliminates the need to call external sorting algorithms.

2. Pre-Order (Node → Left → Right) Serialization

Visits the node first, then recursively descends children. System Application: Essential for cloning and serializing tree hierarchies to disk or JSON, because rebuilding an AVL tree from a pre-order stream preserves parent-child root topologies.

3. Post-Order (Left → Right → Node) Bottom-Up Deletion

Visits both children before processing the parent. System Application: Used in language interpreters to evaluate Mathematical Abstract Syntax Trees (ASTs) and safe bottom-up memory deallocation where children must be freed before parents.

4. Level-Order (Breadth-First Search) Queue-Driven

Visits nodes layer-by-layer horizontally from root to leaves. System Application: Implemented iteratively using collections.deque. Used to inspect balancing topologies, calculate maximum branching widths, and reconstruct trees layer-by-layer.

Part 04

MemForge Milestone 08: Balanced AVL Tree Index Implementation

We now assemble Milestone 08 of MemForge. We implement src/memforge/index/avl_tree.py: an in-memory self-balancing AVL secondary index tree.

The AVL Tree Index enforces:

  • Strict $O(\log n)$ worst-case insertion and search by performing automatic LL, RR, LR, and RL rotations.
  • Support for multi-value duplicates: each node stores an array of corresponding record_ids.
  • Safe Deletion with In-Order Successor: Removing a node with two children cleanly splices the smallest node from the right subtree into the target slot and rebalances the tree.
  • Range Scans with Pruned Branching: Prunes subtrees outside the query interval $[v_{\min}, v_{\max}]$, executing in $O(\log n + k)$ time where $k$ is matching elements.

1. Production AVL Index: src/memforge/index/avl_tree.py Self-Balancing Binary Search Tree 
# ==============================================================================
# MemForge Index Engine - Self-Balancing AVL Secondary Index Tree (Milestone 08)
# ==============================================================================

from collections import deque
from typing import Any, Iterator, List, Optional, Tuple


class AVLNode:
    """Discrete AVL Tree node maintaining cached height and duplicate record IDs."""
    def __init__(self, key: Any, record_id: int):
        self.key = key
        self.record_ids: List[int] = [record_id]
        self.left: Optional["AVLNode"] = None
        self.right: Optional["AVLNode"] = None
        self.height: int = 1  # Leaf nodes initialize with height 1


class BalancedTreeIndex:
    """
    PRODUCTION AVL BALANCED SECONDARY INDEX:
    Maintains Balance Factor in {-1, 0, +1} across all nodes.
    Guarantees strict O(log n) search, insert, and delete boundaries.
    """
    def __init__(self):
        self._root: Optional[AVLNode] = None
        self._total_entries = 0

    def __len__(self) -> int:
        """Returns total record ID entries indexed across all unique keys."""
        return self._total_entries

    def _get_height(self, node: Optional[AVLNode]) -> int:
        """Returns cached height, or 0 if node is None."""
        return node.height if node else 0

    def _get_balance(self, node: Optional[AVLNode]) -> int:
        """Balance Factor = height(left) - height(right)."""
        if not node:
            return 0
        return self._get_height(node.left) - self._get_height(node.right)

    def _update_height(self, node: AVLNode) -> None:
        """Updates node height based on child maximums."""
        node.height = 1 + max(self._get_height(node.left), self._get_height(node.right))

    def _rotate_right(self, y: AVLNode) -> AVLNode:
        """
        Single Right Rotation (LL Case):
             y                x
            / \              / \
           x   T3   →       T1  y
          / \                  / \
         T1  T2               T2  T3
        """
        x = y.left
        T2 = x.right

        # Perform rotation
        x.right = y
        y.left = T2

        # Update heights (y first, then x)
        self._update_height(y)
        self._update_height(x)
        return x

    def _rotate_left(self, x: AVLNode) -> AVLNode:
        """
        Single Left Rotation (RR Case):
           x                  y
          / \                / \
         T1  y      →       x   T3
            / \            / \
           T2  T3         T1  T2
        """
        y = x.right
        T2 = y.left

        # Perform rotation
        y.left = x
        x.right = T2

        # Update heights (x first, then y)
        self._update_height(x)
        self._update_height(y)
        return y

    def insert(self, key: Any, record_id: int) -> None:
        """Inserts a record pointer, rebalancing along the ascent path in O(log n)."""
        self._root = self._insert_recursive(self._root, key, record_id)
        self._total_entries += 1

    def _insert_recursive(self, node: Optional[AVLNode], key: Any, record_id: int) -> AVLNode:
        # 1. Standard BST Insertion
        if not node:
            return AVLNode(key, record_id)

        if key == node.key:
            # Key collision: Append duplicate record_id without structural change
            node.record_ids.append(record_id)
            return node
        elif key < node.key:
            node.left = self._insert_recursive(node.left, key, record_id)
        else:
            node.right = self._insert_recursive(node.right, key, record_id)

        # 2. Update height of current ancestor node
        self._update_height(node)

        # 3. Compute Balance Factor
        balance = self._get_balance(node)

        # 4. Execute Rotations if Unbalanced
        # Case 1: Left-Left (LL)
        if balance > 1 and key < node.left.key:
            return self._rotate_right(node)

        # Case 2: Right-Right (RR)
        if balance < -1 and key > node.right.key:
            return self._rotate_left(node)

        # Case 3: Left-Right (LR)
        if balance > 1 and key > node.left.key:
            node.left = self._rotate_left(node.left)
            return self._rotate_right(node)

        # Case 4: Right-Left (RL)
        if balance < -1 and key < node.right.key:
            node.right = self._rotate_right(node.right)
            return self._rotate_left(node)

        return node

    def find_exact(self, key: Any) -> List[int]:
        """Point lookup returning matching record IDs in O(log n)."""
        current = self._root
        while current:
            if key == current.key:
                return current.record_ids.copy()
            elif key < current.key:
                current = current.left
            else:
                current = current.right
        return []

    def inorder_traversal(self) -> Iterator[Tuple[Any, List[int]]]:
        """
        IN-ORDER DEPTH-FIRST TRAVERSAL:
        Yields (key, record_ids) tuples in strictly ascending sorted order.
        """
        yield from self._inorder_recursive(self._root)

    def _inorder_recursive(self, node: Optional[AVLNode]) -> Iterator[Tuple[Any, List[int]]]:
        if node:
            yield from self._inorder_recursive(node.left)
            yield (node.key, node.record_ids)
            yield from self._inorder_recursive(node.right)

    def level_order_traversal(self) -> List[List[Any]]:
        """
        BREADTH-FIRST SEARCH (BFS):
        Traverses tree level-by-level using an in-memory queue.
        """
        if not self._root:
            return []

        results: List[List[Any]] = []
        queue = deque([self._root])

        while queue:
            level_size = len(queue)
            current_level: List[Any] = []
            for _ in range(level_size):
                node = queue.popleft()
                current_level.append(node.key)
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            results.append(current_level)

        return results

    def range_scan(self, min_val: Any, max_val: Any) -> List[int]:
        """
        PRUNED RANGE SCAN [min_val, max_val]:
        Selectively descends subtrees, pruning irrelevant branches.
        Complexity: O(log n + k) where k is matching records.
        """
        results: List[int] = []
        self._range_recursive(self._root, min_val, max_val, results)
        return results

    def _range_recursive(self, node: Optional[AVLNode], min_val: Any, max_val: Any, out: List[int]) -> None:
        if not node:
            return

        # Only descend left if current key is strictly greater than min
        if node.key > min_val:
            self._range_recursive(node.left, min_val, max_val, out)

        # Capture matches within closed interval [min_val, max_val]
        if min_val <= node.key <= max_val:
            out.extend(node.record_ids)

        # Only descend right if current key is strictly less than max
        if node.key < max_val:
            self._range_recursive(node.right, min_val, max_val, out)

import pytest
from memforge.index.avl_tree import BalancedTreeIndex

class TestBalancedTreeIndex:
    """Unit tests asserting AVL rotations, invariant enforcement, and traversal sorting."""

    def test_adversarial_sorted_insert_prevents_degeneration(self):
        index = BalancedTreeIndex()
        # Monotonically increasing sequence: In a naive BST, height would be 7!
        keys = [10, 20, 30, 40, 50, 60, 70]
        for i, k in enumerate(keys):
            index.insert(key=k, record_id=i)

        assert len(index) == 7

        # AVL Invariant Guarantee: Maximum height for 7 nodes is exactly 3!
        assert index._get_height(index._root) <= 3

        # The root must have been rotated away from 10 to a median key
        assert index._root.key == 40  # Perfectly balanced root

    def test_double_rotation_left_right_case(self):
        index = BalancedTreeIndex()
        # Triggers LR Case: Insert 30, then 10, then 20 (inner child)
        index.insert(30, 1)
        index.insert(10, 2)
        index.insert(20, 3)

        assert index._root.key == 20  # 20 pulled to root
        assert index._root.left.key == 10
        assert index._root.right.key == 30
        assert index._get_height(index._root) == 2

    def test_inorder_traversal_yields_strictly_sorted_keys(self):
        index = BalancedTreeIndex()
        unsorted_input = [(42, 1), (15, 2), (88, 3), (8, 4), (23, 5), (65, 6)]
        for k, rid in unsorted_input:
            index.insert(k, rid)

        sorted_keys = [k for k, _ in index.inorder_traversal()]
        assert sorted_keys == [8, 15, 23, 42, 65, 88]

    def test_level_order_breadth_first_structure(self):
        index = BalancedTreeIndex()
        # Insert sequence: 20, 10, 30
        index.insert(20, 1)
        index.insert(10, 2)
        index.insert(30, 3)

        levels = index.level_order_traversal()
        assert levels == [
            [20],        # Level 0 (Root)
            [10, 30]     # Level 1
        ]

    def test_pruned_range_scan_bounds(self):
        index = BalancedTreeIndex()
        for val in range(10, 110, 10):  # 10, 20, ..., 100
            index.insert(val, record_id=val // 10)

        # Range scan [30, 70]
        records = index.range_scan(min_val=30, max_val=70)
        assert records == [3, 4, 5, 6, 7]  # Matching record IDs
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Forgetting Height Updates During Rotations

Writing pointer rotation code without explicitly recalculating child and parent heights.

Why this breaks trees: Rotations physically rearrange the parent-child hierarchy. If heights are not updated immediately (updating the demoted node first, then the promoted root), all subsequent balance_factor queries use stale data, causing the tree to fail to balance future insertions!

❌ Sorting the Output of a BST

Writing sorted(tree.get_all_keys()) to produce sorted records.

Why this is redundant: Calling sorted() forces an $O(n \log n)$ Timsort pass. A Binary Search Tree already maintains strict sorted invariants; executing a generator-based In-Order Traversal yields elements in perfect ascending order in $O(n)$ with zero extra sorting overhead!

❌ Recursive Stack Overflow on Degenerate Trees

Using naive recursion on an unbalanced binary tree with 50,000 sequential elements.

Why this crashes the process: In a degenerate tree of height $h=n$, recursion depth reaches $n$. Python's default call stack limit is 1,000 frames (sys.getrecursionlimit()), raising RecursionError: maximum recursion depth exceeded. Self-balancing AVL trees keep height strictly bounded at $\approx 1.44 \log_2 n \le 25$, never exceeding stack limits!

❌ Corrupting Two-Child Node Deletions

Deleting an internal node with two children by directly splicing child pointers.

Why this orphans subtrees: An internal node has two subtrees that cannot be attached to a single parent slot. Fix: Replace the target node's key with its In-Order Successor (the minimum node in its right subtree), and then recursively delete the successor from the right subtree.
