Part 01

Computer Science: The O(L) Retrieval Invariant & Character Edges

Comparing strings in a standard Binary Search Tree or B-Tree is computationally expensive. Evaluating string equality or ordering (str_a < str_b) is not $O(1)$; it requires scanning characters up to length $L$. Thus, searching a binary tree of $N$ strings takes $O(L \log N)$ time.

Invented by René de la Briandais (1959) and Edward Fredkin (1960), the Trie (derived from retrieval, pronounced "try") restructures string storage completely. Instead of storing entire words inside nodes, words are formed by tracing paths along character edges.

Prefix Tree Topology: Storing ["cat", "car", "card", "dog"]

Common prefixes share physical ancestor nodes; terminal flags designate complete words

(Root) is_terminal: False
↙ edge 'c' edge 'd' ↘
Node 'c' prefix: "c"
Node 'd' prefix: "d"
↓ edge 'a' ↓ edge 'o'
Node 'a' prefix: "ca"
Node 'o' prefix: "do"
↙ 't' 'r' ↘
↓ 'g'
't' [★] Word: "cat"
'r' [★] Word: "car"
↓ 'd'
'd' [★] "card"
'g' [★] Word: "dog"
The O(L) Independent Search Theorem:

Searching for a word of length $L$ in a Trie requires examining exactly $L$ character transitions down the tree. The search time is completely independent of the total number of words $N$ stored in the database! Whether the index holds 100 words or 50,000,000 words, looking up "cat" takes exactly 3 pointer dereferences.

Part 02

Under the Hood: Standard Tries vs. Radix Trees (Patricia Tries)

While standard Tries provide optimal time complexity, they exhibit a major architectural vulnerability: Memory Fragmentation.

If a collection contains words with long, non-branching sequences (such as URLs like "https://api.memforge.io/v1/auth"), a standard Trie allocates an independent node object for every single character. In Python, each node object plus its internal child dictionary consumes ~150 to 200 bytes of heap memory!

Standard Trie (Uncompressed) 1 Node Per Char

Storing "internationalization" creates 20 sequential node allocations chained together in memory:

(i) → (n) → (t) → (e) → (r) → ... → (n) [★]

Wastes heap allocations on non-branching linear pathways where no other words diverge.

Radix Tree (Patricia Trie) Path Compressed

Invented by Donald R. Morrison (1968), a Radix Tree merges every node that has only one child with its parent, compressing the edge into a substring:

(Root) —["internationalization"]→ (Node) [★]

Reduces total tree node count from $O(\sum \text{length}(w_i))$ to at most $2N - 1$ nodes, slashing memory consumption by up to 70% in URL routing and IP routing tables!

Part 03

Algorithmic Mechanics: Frequency Autocomplete & Wildcards

Tries unlock query capabilities that are virtually impossible to implement efficiently on top of standard B-Trees or hash tables:

1. Typeahead Autocomplete Pipeline Two-Phase Search

When a user types "mem":

  1. Phase 1 (Prefix Navigation): Traverse from root matching characters 'm' → 'e' → 'm' in $O(L)$ time to find the prefix subtree root.
  2. Phase 2 (Subtree Extraction): Execute a Depth-First Search (DFS) from that subtree node to collect all descending terminal words.
  3. Ranking: Sort the collected matches by popularity weight or usage frequency to return the Top-$K$ suggestions.
2. Single-Character Wildcard Matching Regex '.' Support

When a search query contains a wildcard like "c.t" (where '.' matches any character):

  • Standard character: follow the specific character edge matching the pattern.
  • Wildcard character '.': branch recursively across all child edges currently attached to the node!
  • Matches "cat", "cot", "cut" in a single unified traversal.
Part 04

MemForge Milestone 10: Autocomplete Search Engine Implementation

We now assemble Milestone 10 of MemForge. We implement src/memforge/index/trie.py: a production prefix search and autocomplete index.

The Autocomplete Engine features:

  • Strict $O(L)$ exact point lookups and boolean starts_with() prefix validation.
  • Weighted Top-K Autocomplete: Returns query suggestions ranked by usage frequency or popularity weight.
  • Wildcard Matching: Supports single-character wildcard search ('.') through recursive DFS branching.
  • Recursive Post-Order Pruning Deletion: Deleting a word unmarks its terminal status and cleans up empty child nodes upwards, eliminating memory leaks.

1. Production Search Engine: src/memforge/index/trie.py Prefix Tree & Typeahead Engine 
# ==============================================================================
# MemForge Index Engine - Prefix Tree (Trie) & Autocomplete Engine (Milestone 10)
# ==============================================================================

from typing import Dict, List, Optional, Tuple


class TrieNode:
    """Discrete character edge transition node in the prefix tree."""
    def __init__(self):
        # Character transition mapping: char -> TrieNode
        self.children: Dict[str, "TrieNode"] = {}
        # Indicates if a complete word terminates at this node
        self.is_terminal: bool = False
        # Record IDs mapped to this word
        self.record_ids: List[int] = []
        # Popularity ranking weight (higher = ranks higher in autocomplete)
        self.weight: int = 0


class AutocompleteSearchEngine:
    """
    PRODUCTION TRIE SEARCH & AUTOCOMPLETE ENGINE:
    Delivers O(L) exact matches and prefix searches independent of total dataset size.
    Supports frequency-ranked autocomplete and single-character wildcard search.
    """
    def __init__(self):
        self._root = TrieNode()
        self._total_words = 0

    def __len__(self) -> int:
        """Returns total distinct words indexed in the Trie."""
        return self._total_words

    def insert(self, word: str, record_id: int, weight: int = 1) -> None:
        """
        Inserts a word into the tree in O(L) time where L = len(word).
        Appends record_id and updates popularity ranking weight.
        """
        if not word:
            return

        current = self._root
        for char in word:
            if char not in current.children:
                current.children[char] = TrieNode()
            current = current.children[char]

        if not current.is_terminal:
            current.is_terminal = True
            self._total_words += 1

        current.record_ids.append(record_id)
        current.weight = max(current.weight, weight)

    def search_exact(self, word: str) -> List[int]:
        """
        Returns all record IDs mapped to the exact word in O(L) time.
        Returns empty list if word is absent or not marked terminal.
        """
        node = self._find_node(word)
        if node and node.is_terminal:
            return node.record_ids.copy()
        return []

    def starts_with(self, prefix: str) -> bool:
        """Returns True if any word in the index begins with the given prefix."""
        return self._find_node(prefix) is not None

    def _find_node(self, prefix: str) -> Optional[TrieNode]:
        """Traverses down character edges, returning the node representing the prefix."""
        current = self._root
        for char in prefix:
            if char not in current.children:
                return None
            current = current.children[char]
        return current

    def autocomplete(self, prefix: str, limit: int = 5) -> List[Tuple[str, int]]:
        """
        TYPEAHEAD SUGGESTION ENGINE:
        1. Navigates to prefix node in O(L) time.
        2. Gathers all descending terminal words via DFS.
        3. Returns top-k suggestions sorted by popularity weight.
        """
        prefix_node = self._find_node(prefix)
        if not prefix_node:
            return []

        candidates: List[Tuple[str, int]] = []
        self._dfs_collect(prefix_node, list(prefix), candidates)

        # Sort candidates descending by weight, then alphabetically by word
        candidates.sort(key=lambda item: (-item[1], item[0]))
        return candidates[:limit]

    def _dfs_collect(
        self,
        node: TrieNode,
        current_chars: List[str],
        results: List[Tuple[str, int]]
    ) -> None:
        """Recursive DFS collecting all words descending from node."""
        if node.is_terminal:
            results.append(("".join(current_chars), node.weight))

        for char, child_node in node.children.items():
            current_chars.append(char)
            self._dfs_collect(child_node, current_chars, results)
            current_chars.pop()  # Backtrack

    def search_wildcard(self, pattern: str) -> List[str]:
        """
        WILDCARD MATCHING:
        Supports single-character wildcards using '.' (e.g. 'c.t' matches 'cat', 'cot').
        """
        matches: List[str] = []
        self._wildcard_recursive(self._root, pattern, 0, [], matches)
        return matches

    def _wildcard_recursive(
        self,
        node: TrieNode,
        pattern: str,
        index: int,
        current_chars: List[str],
        matches: List[str]
    ) -> None:
        if index == len(pattern):
            if node.is_terminal:
                matches.append("".join(current_chars))
            return

        char = pattern[index]
        if char == '.':
            # Wildcard branch: Explore every child edge
            for child_char, child_node in node.children.items():
                current_chars.append(child_char)
                self._wildcard_recursive(child_node, pattern, index + 1, current_chars, matches)
                current_chars.pop()
        else:
            # Standard edge navigation
            if char in node.children:
                current_chars.append(char)
                self._wildcard_recursive(node.children[char], pattern, index + 1, current_chars, matches)
                current_chars.pop()

    def delete(self, word: str) -> bool:
        """
        PRUNED DELETION:
        Unmarks terminal status and executes bottom-up recursive pruning
        to deallocate unbranched dead nodes from memory.
        """
        if not word:
            return False

        deleted_flag = [False]
        self._delete_recursive(self._root, word, 0, deleted_flag)
        if deleted_flag[0]:
            self._total_words -= 1
        return deleted_flag[0]

    def _delete_recursive(
        self,
        node: TrieNode,
        word: str,
        index: int,
        deleted_flag: List[bool]
    ) -> bool:
        """Returns True if the child node should be pruned by its parent."""
        if index == len(word):
            if not node.is_terminal:
                return False  # Word was not in the Trie

            node.is_terminal = False
            node.record_ids.clear()
            deleted_flag[0] = True
            # Prune this node only if it has zero child branches
            return len(node.children) == 0

        char = word[index]
        if char not in node.children:
            return False

        should_prune_child = self._delete_recursive(node.children[char], word, index + 1, deleted_flag)

        if should_prune_child:
            del node.children[char]
            # Prune this ancestor node if it is not terminal and has no remaining children
            return not node.is_terminal and len(node.children) == 0

        return False

# MemForge Test Suite - Trie Autocomplete Engine Verification (Milestone 10)
# ==============================================================================

import pytest
from memforge.index.trie import AutocompleteSearchEngine

class TestAutocompleteSearchEngine:
    """Unit tests asserting prefix lookups, frequency ranking, wildcards, and node pruning."""

    def test_exact_search_and_prefix_existence(self):
        engine = AutocompleteSearchEngine()
        engine.insert("memforge", record_id=101)
        engine.insert("memory", record_id=102)
        engine.insert("database", record_id=201)

        assert len(engine) == 3
        assert engine.search_exact("memforge") == [101]
        assert engine.search_exact("mem") == []  # Prefix exists, but not terminal!
        assert engine.starts_with("mem") is True
        assert engine.starts_with("data") is True
        assert engine.starts_with("redis") is False

    def test_frequency_ranked_autocomplete(self):
        engine = AutocompleteSearchEngine()
        # Insert terms with distinct popularity weights
        engine.insert("apple", record_id=1, weight=50)
        engine.insert("application", record_id=2, weight=100)  # Highest weight
        engine.insert("app", record_id=3, weight=10)
        engine.insert("banana", record_id=4, weight=90)

        # Autocomplete query "app"
        results = engine.autocomplete("app", limit=3)
        assert len(results) == 3

        # Must be ranked descending by weight: application (100) → apple (50) → app (10)
        assert results[0] == ("application", 100)
        assert results[1] == ("apple", 50)
        assert results[2] == ("app", 10)

    def test_single_character_wildcard_matching(self):
        engine = AutocompleteSearchEngine()
        engine.insert("cat", record_id=1)
        engine.insert("cot", record_id=2)
        engine.insert("cut", record_id=3)
        engine.insert("cart", record_id=4)
        engine.insert("dog", record_id=5)

        # Query "c.t" must match cat, cot, cut, but NOT cart or dog
        matches = sorted(engine.search_wildcard("c.t"))
        assert matches == ["cat", "cot", "cut"]

    def test_pruned_deletion_cleans_memory(self):
        engine = AutocompleteSearchEngine()
        engine.insert("car", record_id=1)
        engine.insert("card", record_id=2)

        assert len(engine) == 2
        # Node 'r' has child 'd'
        node_r = engine._find_node("car")
        assert 'd' in node_r.children

        # Delete "card" -> must prune 'd', leaving "car" untouched
        assert engine.delete("card") is True
        assert len(engine) == 1
        assert engine.search_exact("card") == []
        assert engine.search_exact("car") == [1]
        assert 'd' not in node_r.children  # Pruned!

        # Delete "car" -> must prune 'c', 'a', 'r' entirely from root!
        assert engine.delete("car") is True
        assert len(engine) == 0
        assert 'c' not in engine._root.children  # Root completely empty!
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Array[26] Allocation per Node in Python

Porting C/Java code by allocating children = [None] * 26 in every Trie node.

Why this thrashes RAM: In C, 26 pointers take 208 bytes flat. In Python, a 26-slot list is an entire PyListObject with pointer tables, allocating ~270 bytes per node even if only 1 character is present. Furthermore, it restricts input strictly to ASCII lowercase! Fix: Use a dynamic Python dictionary children: dict[str, TrieNode] = {}, allocating memory strictly on demand and natively supporting UTF-8 unicode.

❌ Failing to Prune Dead Nodes on Deletion

Implementing deletion simply as node.is_terminal = False without unlinking dead children.

Why this causes memory leaks: In high-churn databases where millions of ephemeral tokens or session IDs are inserted and removed, unmarking the terminal flag leaves dead unbranched node chains permanently rooted in memory. Fix: Execute recursive post-order pruning: if a child is non-terminal and has no remaining children, remove it from the parent dictionary.

❌ Using SQL LIKE '%term%' for Autocomplete

Executing SELECT * FROM items WHERE name LIKE 'prefix%' on every user keystroke.

Why this saturates databases: Relational engines must either scan B-Tree indexes or execute full sequential table scans, locking database worker threads. Fix: Route typeaheads into an in-memory Trie index, returning autocompletions in sub-millisecond $O(L)$ time with zero relational database load.

❌ Unbounded DFS Extraction in Autocomplete

Gathering all 250,000 matches descending from a broad prefix like "a" before slicing [:5].

Why this spikes latency: Deep tree traversal over hundreds of thousands of words wastes milliseconds of CPU time just to display 5 suggestions in a UI dropdown. Fix: Maintain a bounded Priority Queue (Min-Heap of size $K$) or track top-ranked children directly on ancestor nodes to truncate search early.
