A Index

Adjacency List

Graph • Ch. 11

A graph representation mapping every vertex to an associative list or dictionary of its outgoing neighbors. Consumes optimal $O(|V| + |E|)$ memory, making it the industry standard for real-world sparse graphs.

Adjacency Matrix

Graph • Ch. 11

A 2D square matrix of size $|V| \times |V|$ where cell $(u, v)$ stores edge existence or weight. Grants $O(1)$ edge queries, but consumes prohibitive $O(|V|^2)$ memory, thrashing RAM on large sparse networks.

Amortized Time Complexity

Analysis • Ch. 01

The average cost per operation over a sequence of actions. For example, list.append() occasionally triggers an expensive $O(n)$ reallocation, but because capacity grows geometrically, the average cost over $N$ appends is strictly $O(1)$.

array.array

Standard Lib • Ch. 01

A standard library sequence storing homogeneous C-style primitive scalar types (integers, floats) packed directly into contiguous memory without PyObject pointer wrapping, saving up to 75% RAM over lists.

AVL Tree

Trees • Ch. 08

The earliest self-balancing binary search tree (Adelson-Velsky & Landis, 1962). Enforces that the balance factors of all nodes remain within $\{-1, 0, 1\}$, executing single or double rotations to guarantee strict $O(\log n)$ worst-case operations.

B Index

B-Tree (Multi-Way Tree)

Storage • Ch. 09

A self-balancing search tree with a high branching factor (degree $t$). Nodes hold multiple contiguous keys and children, aligning with 4KB memory blocks and shrinking tree height to $O(\log_t n)$ to minimize pointer hops.

B+ Tree

Database • Ch. 09

The standard database engine variant of B-Trees: internal nodes store routing keys exclusively, while all records reside in leaves linked together in a doubly linked chain, enabling linear-time range scans ($O(k)$).

Balance Factor (AVL)

Trees • Ch. 08

In an AVL tree node $N$, the height of the left subtree minus the height of the right subtree: $\text{BF}(N) = \text{height}(N.\text{left}) - \text{height}(N.\text{right})$. Exceeding $|\text{BF}| > 1$ triggers rebalancing rotations.

Binary Heap

Priority • Ch. 05

A complete binary tree packed into a flat array without pointers where parent nodes satisfy the heap invariant ($\text{val}(\text{parent}) \le \text{val}(\text{child})$ for a Min-Heap). Powers $O(\log n)$ priority queues.

bisect Module

Standard Lib • Ch. 06

CPython's C-accelerated binary search library providing bisect_left and bisect_right. Locates insertion boundaries and slices sorted numeric range intervals in $O(\log n)$ time.

Breadth-First Search (BFS)

Traversal • Ch. 08, 11

A queue-driven graph and tree traversal exploring vertices layer-by-layer. Mathematically guaranteed to discover the shortest path on unweighted graphs in $O(|V| + |E|)$ time.

bytearray

Built-in • Ch. 01

A mutable sequence of raw 8-bit bytes ($0 \le x \le 255$) packed contiguously in memory. Supports in-place slice mutation and exposes the CPython buffer protocol without pointer indirection.

C Index

collections.ChainMap

Mapping • Ch. 03

A mapping primitive grouping multiple dictionaries into a single layered view without copying memory. Searches cascade through layers sequentially from local overrides to global defaults.

Compact Dictionary Layout

CPython • Ch. 02

The internal CPython dictionary architecture (since Python 3.6) combining a sparse 1-byte indices array with a dense packed entries array, saving 25% memory and preserving insertion order by default.

ContiguousBuffer

MemForge • Ch. 01

The raw binary write-ahead logging (WAL) component in MemForge. Pre-allocates contiguous heap RAM and returns non-allocating memoryview slices for zero-copy read operations.

collections.Counter

Multiset • Ch. 03

A specialized dictionary subclass designed for counting hashable items. Implements multiset bag algebra (unions, intersections, additions) and extracts top-$k$ elements in $O(n \log k)$ time via most_common().

Cyclic Garbage Collection

CPython • Ch. 07

CPython's secondary generational garbage collector that detects circular pointer loops (such as doubly linked lists referencing next ⇔ prev) where standard reference counts never reach zero.

D Index

collections.defaultdict

Mapping • Ch. 03

A dictionary subclass that overrides the __missing__ protocol. When an absent key is accessed via d[key], it automatically invokes a configured factory function (e.g. list, int), avoiding missing-key boilerplate.

collections.deque

Sequence • Ch. 04

A double-ended queue implemented in CPython as a doubly-linked list of 64-element arrays (BLOCKLEN=64). Provides true $O(1)$ appends and pops at both ends without array memory-shifting penalties.

Depth-First Search (DFS)

Traversal • Ch. 08, 11

A graph and tree traversal exploring as deep as possible along each branch before backtracking. Powers cycle detection algorithms via 3-color vertex marking (UNVISITED, VISITING, VISITED).

Dijkstra's Shortest Path Algorithm

Pathfinding • Ch. 11

A greedy pathfinding algorithm that finds the single-source lowest-cost route across non-negative weighted graphs in $O((|V| + |E|) \log |V|)$ time when accelerated by a binary Min-Heap (heapq).

Doubly Linked List

Pointer • Ch. 07

A linked structure where every node holds explicit pointers to both its predecessor (prev) and successor (next). Enables true $O(1)$ arbitrary node deletion given an address pointer.

E Index

Edge Relaxation (Dijkstra)

Pathfinding • Ch. 11

The process of checking whether reaching vertex $v$ through intermediate vertex $u$ yields a lower cumulative distance than the currently known shortest path: if dist[u] + w < dist[v]: dist[v] = dist[u] + w.

F Index

Fan-Out Theorem (B-Tree)

Storage • Ch. 09

The architectural principle proving that expanding tree branching from binary ($B=2$) to multi-way ($B=100+$) flattens tree height from $O(\log_2 n)$ to $O(\log_B n)$, packing contiguous keys into hardware blocks and eliminating pointer hops.

FixedRecordArray

MemForge • Ch. 01

The compact index array in MemForge storing 64-bit unsigned integer offsets using Python's native array.array('Q'), taking exactly 8 bytes per record with zero PyObject pointer overhead.

Floyd's Cycle Algorithm

Algorithms • Ch. 07

The "Tortoise and Hare" pointer algorithm. Advances a slow pointer 1 step and a fast pointer 2 steps to detect circular loops in pointer structures in $O(n)$ time with strictly $O(1)$ auxiliary memory.

Floyd's Linear Heapify ($O(n)$)

Priority • Ch. 05

The bottom-up sifting algorithm used by heapq.heapify(). Because the vast majority of tree nodes reside at or near leaf levels where downward sift distance is short, the aggregate work converges to linear time $O(n)$.

Forward Index

Search • Ch. 12

The standard document storage format mapping an entity identifier to its list of text tokens: $\text{DocID} \to [w_1, w_2, \dots]$. Optimal for retrieving full documents, but slow for searching words across the corpus.

G Index

GraphRelationshipEngine

MemForge • Ch. 11

The entity relationship module built in MemForge Milestone 11. Stores connections in a sparse adjacency list, tracks degrees of separation with BFS, detects cycle deadlocks, and resolves optimal path costs with Dijkstra.

H Index

Hashability Contract

CPython • Ch. 02

The strict invariant governing Python dictionary keys and sets: an object must implement immutable __hash__() and __eq__() such that if a == b is True, then hash(a) == hash(b) must also be True.

heapq Module

Standard Lib • Ch. 05

Python's built-in C-accelerated binary Min-Heap algorithms. Operates directly on standard Python lists in-place, delivering $O(\log n)$ heappush, heappop, and $O(n)$ heapify.

I Index

In-Order Traversal

Trees • Ch. 08, 09

A depth-first tree traversal visiting left subtree, current node, then right subtree. In any valid Binary Search Tree or B-Tree, an in-order traversal yields keys in strictly ascending sorted order in $O(n)$ time.

Inverted Index

Search • Ch. 12

The architectural foundation of search engines: maps discrete word tokens to sorted posting lists of document IDs. Enables instant Boolean searches and relevance ranking without scanning whole documents.

K Index

Kahn's Algorithm

Graph • Ch. 11

A topological sorting algorithm that repeatedly extracts vertices with in-degree 0. Resolves compilation sequences and database migration dependencies in $O(|V| + |E|)$ time and detects cyclic deadlocks.

L Index

list (Referential Dynamic Array)

Built-in • Ch. 01

CPython's primary dynamic sequence. Stores a contiguous array of 64-bit memory addresses (pointers) pointing to scattered PyObject structures rather than storing raw data inline.

LRU Buffer Pool

Cache • Ch. 04

A memory management subsystem combining an $O(1)$ hash directory with a double-ended queue (deque). Tracks recency, evicts oldest pages when full, and respects transactional page pinning.

M Index

MemBTreeIndex

MemForge • Ch. 09

The multi-way B-Tree secondary range index engineered in MemForge Milestone 09. Implements proactive top-down node splitting, multi-value duplicate handling, and pruned subtree range scanning.

MemForge Project

Capstone • Ch. 01–12

The continuous institutional in-memory multi-model storage engine built incrementally across the 12 chapters to demonstrate low-level buffers, custom hash tables, priority heaps, trees, tries, and graphs.

memoryview

Built-in • Ch. 01

A built-in Python wrapper exposing the C-level Buffer Protocol. Slicing a memoryview creates an address window over existing memory with zero memory copies, running in $O(1)$ time and space.

__missing__ Protocol

CPython • Ch. 03

The dunder method called by CPython dictionary subclasses when d[key] fails to find an entry. Powers defaultdict by auto-instantiating default values.

O Index

Open Addressing

Hash Table • Ch. 02

A collision resolution strategy where all entries reside directly in the table array. Collisions trigger deterministic probe sequences, avoiding linked-list pointer overhead and maximizing CPU cache locality.

collections.OrderedDict

Mapping • Ch. 03

A dictionary augmented with an internal doubly-linked key ring. Unlocks $O(1)$ in-place reordering via .move_to_end() and bidirectional FIFO/LIFO pops via .popitem().

P Index

Pathological Degeneration

Trees • Ch. 08

The vulnerability where inserting pre-sorted data into a naive Binary Search Tree collapses branching completely, producing a single-chain linked list of height $h=n$ and degrading search from $O(\log n)$ to $O(n)$.

Perturbation Probing

CPython • Ch. 02

CPython's pseudo-random recurrence probe relation: $i = (5i + 1 + \text{perturb}) \pmod{\text{size}}$. Systematically consumes all 64 bits of the original hash code, preventing the clustering bottlenecks of simple linear probing.

Posting List

Search • Ch. 12

A strictly sorted list of Document IDs associated with a specific term in an Inverted Index. Sorted ordering enables linear two-pointer intersections for Boolean AND searches in $O(L_1 + L_2)$ time.

R Index

Radix Tree (Patricia Trie)

Trees • Ch. 10

A space-optimized prefix tree that compresses non-branching node pathways into composite substring edges. Eliminates up to 70% of heap allocations compared to standard single-character Tries.

Tree Rotations (AVL)

Trees • Ch. 08

Local pointer reassignments (Single Right LL, Single Left RR, Double LR, Double RL) that restore the height balance invariant in $O(1)$ time without violating the binary search ordering of keys.

S Index

Sentinel (Dummy) Node

Architecture • Ch. 07

Fixed dummy head and tail nodes placed at linked list extremities. Ensures that every real node always possesses non-null prev and next neighbors, eliminating 100% of null-check branch conditions during insertion and deletion.

SipHash-13

Security • Ch. 02

The cryptographically resilient hash algorithm adopted in Python 3.4 (PEP 456) for strings and bytes. Seeds string hashing with a randomized 128-bit key per process boot, defusing algorithmic complexity hash-flooding DoS attacks.

T Index

TF-IDF

Search • Ch. 12

Term Frequency – Inverse Document Frequency: a mathematical scoring formula measuring term prominence inside a document balanced against its global rarity across the corpus to rank full-text search results by relevance.

Timsort

Algorithms • Ch. 01, 06

Python's standard in-place sorting algorithm (Tim Peters, 2002). A hybrid adaptive mergesort and binary insertion sort that detects ordered natural "runs", delivering $O(n)$ best-case and guaranteed $O(n \log n)$ worst-case performance.

Tombstone Marker

Architecture • Ch. 02, 05

A sentinel marker (<DUMMY>) substituted into deleted slots in open-addressing hash tables or priority queues. Preserves probe chain continuity so subsequent collided keys remain discoverable.

Topological Sort

Graph • Ch. 11

A linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every directed edge $u \to v$, $u$ appears before $v$. Essential for resolving transaction cascades, build pipelines, and foreign-key constraints.

Trie (Prefix Tree)

Trees • Ch. 10

A retrieval tree where character edges form words and nodes validate prefixes. Provides $O(L)$ search and autocomplete times strictly bounded by key length $L$, independent of total dataset volume $N$.

tuple

Built-in • Ch. 01

An immutable fixed-length referential sequence. Allocates memory for exact lengths with zero over-allocation, reuses memory via CPython freelists, and provides hashability when containing immutable items.

U Index

Transaction Undo Log

MemForge • Ch. 07

The transactional rollback engine built in MemForge Milestone 07. Links compensating operations in a sentinel doubly linked list, traversing backwards from tail to head to restore original states on aborts.

W Index

Write-Ahead Log (WAL)

Storage • Ch. 01

An append-only binary recording structure where mutations are logged sequentially before updating indexes or in-memory tables. Guarantees ACID durability and crash recovery.

Z Index

Zero-Copy Slicing

Optimization • Ch. 01, 03

The technique of referencing sub-regions of existing memory buffers or collections via pointer views (memoryview, ChainMap) rather than allocating new heap objects and copying payload data.
