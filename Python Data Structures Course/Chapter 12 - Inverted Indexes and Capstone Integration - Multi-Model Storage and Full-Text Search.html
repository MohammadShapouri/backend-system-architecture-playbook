Part 01

Computer Science: Forward vs. Inverted Indexes & Posting Lists

Relational databases and document stores naturally store data in a Forward Index format: given a document or record identifier, retrieve its corresponding text fields ($DocID \to [w_1, w_2, \dots, w_k]$). While optimal for reading complete records, finding all documents containing the phrase "distributed transaction" requires scanning every single document across the entire table ($O(N)$ linear scan).

Industrial search engines (such as Apache Lucene, Elasticsearch, and Google) invert this mapping into an Inverted Index:

Term (Token) → Posting List: [Sorted Document IDs + Frequency Counts]
The Inverted Index Architecture & Two-Pointer Sweep Intersection
Forward Index (Document → Text)
Doc 1: "database memory buffer transaction"
Doc 2: "transaction rollback undo log"
Doc 3: "memory cache transaction index"

Requires full O(N) scan to answer: "Which documents contain both 'memory' AND 'transaction'?"

Inverted Index (Term → Sorted Postings)
"memory": [Doc 1, Doc 3]
"transaction": [Doc 1, Doc 2, Doc 3]
"rollback": [Doc 2]

Query "memory" AND "transaction": Two-pointer sweep intercepts [Doc 1, Doc 3] in O(L₁ + L₂) time!

// Two-Pointer Linear Intersection Algorithm:

Because posting lists are maintained in strictly ascending DocID order, computing a Boolean AND query avoids nested loops. We place pointer $p_1$ on List 1 and $p_2$ on List 2:

  • If $L_1[p_1] == L_2[p_2]$: Match found! Append DocID to output, advance both $p_1$ and $p_2$.
  • If $L_1[p_1] < L_2[p_2]$: Advance pointer $p_1$.
  • If $L_1[p_1] > L_2[p_2]$: Advance pointer $p_2$.
  • Terminates in linear time: exactly $\mathbf{O(|L_1| + |L_2|)}$ operations!
Part 02

Algorithmic Mechanics: TF-IDF Text Relevance Scoring

Boolean search determines which documents contain the query terms, but it provides zero insight into which document is most relevant.

To order search results by semantic relevance, search engines apply TF-IDF (Term Frequency - Inverse Document Frequency):

1. Term Frequency (TF) Local Weight

Measures how frequently term $t$ appears inside a specific document $d$:

TF(t, d) = count(t in d) / total_words(d)

A document mentioning "database" 15 times is more relevant than a document mentioning it only once.

2. Inverse Document Frequency (IDF) Global Rarity

Measures how rare or distinctive term $t$ is across the entire corpus of $N$ documents:

IDF(t) = ln(1 + (N / docs_containing(t)))

Common words like "the" or "server" appear in all documents and receive a score near 0. Rare words like "deadlock" receive a high weight!

Composite Relevance Score Formula Score(query, doc) = ∑ [ TF(term, doc) × IDF(term) ]
Top-K Ranked via heapq.nlargest in O(N log K) time!

1. Inverted Search Engine: src/memforge/index/inverted_index.py Boolean Intersections & TF-IDF Ranking 
# ==============================================================================
# MemForge Index Engine - Inverted Document Index & TF-IDF Relevance (Milestone 12)
# ==============================================================================

import math
import re
from collections import Counter, defaultdict
from typing import Dict, List, Set, Tuple

# Common stopword noise tokens discarded during tokenization
STOPWORDS: Set[str] = {"the", "is", "at", "which", "on", "a", "an", "in", "and", "or", "to"}


class InvertedIndex:
    """
    PRODUCTION INVERTED DOCUMENT INDEX:
    Maintains sorted posting lists mapping terms to DocIDs.
    Executes O(L1 + L2) Boolean AND/OR queries and calculates TF-IDF relevance.
    """
    def __init__(self):
        # Posting lists: term -> strictly sorted list of unique doc_ids
        self._postings: Dict[str, List[int]] = defaultdict(list)
        # Term frequencies: term -> {doc_id: raw_term_count}
        self._term_frequencies: Dict[str, Dict[int, int]] = defaultdict(dict)
        # Document lengths: doc_id -> total token count
        self._doc_lengths: Dict[int, int] = {}
        # Total unique indexed documents
        self._total_docs: int = 0

    def _tokenize(self, text: str) -> List[str]:
        """Splits text on word boundaries, converts to lowercase, and filters stopwords."""
        tokens = re.findall(r"\w+", text.lower())
        return [t for t in tokens if t not in STOPWORDS]

    def index_document(self, doc_id: int, text: str) -> None:
        """Tokenizes text and appends doc_id to inverted posting lists in O(T) time."""
        tokens = self._tokenize(text)
        if not tokens:
            return

        self._doc_lengths[doc_id] = len(tokens)
        counts = Counter(tokens)

        for term, count in counts.items():
            self._postings[term].append(doc_id)
            self._term_frequencies[term][doc_id] = count

        self._total_docs += 1

    def search_boolean_and(self, terms: List[str]) -> List[int]:
        """
        TWO-POINTER INTERSECTION (AND Query):
        Finds documents containing ALL terms in O(L1 + L2 + ...) linear time.
        """
        cleaned_terms = [t.lower() for t in terms if t.lower() in self._postings]
        if len(cleaned_terms) != len(terms):
            # At least one term is completely absent from the corpus
            return []

        # Sort terms by posting list length ascending to minimize comparisons
        cleaned_terms.sort(key=lambda t: len(self._postings[t]))
        result = self._postings[cleaned_terms[0]]

        for i in range(1, len(cleaned_terms)):
            result = self._intersect_two_lists(result, self._postings[cleaned_terms[i]])
            if not result:
                break

        return result

    def _intersect_two_lists(self, l1: List[int], l2: List[int]) -> List[int]:
        """Linear two-pointer sweep intersecting two sorted lists."""
        out: List[int] = []
        p1 = 0
        p2 = 0
        len1 = len(l1)
        len2 = len(l2)

        while p1 < len1 and p2 < len2:
            if l1[p1] == l2[p2]:
                out.append(l1[p1])
                p1 += 1
                p2 += 1
            elif l1[p1] < l2[p2]:
                p1 += 1
            else:
                p2 += 1
        return out

    def search_ranked_tfidf(self, query: str, limit: int = 5) -> List[Tuple[int, float]]:
        """
        TF-IDF RELEVANCE RANKING:
        Calculates composite relevance score for each matching document.
        Returns top-k documents sorted by score descending.
        """
        tokens = self._tokenize(query)
        if not tokens or self._total_docs == 0:
            return []

        scores: Dict[int, float] = defaultdict(float)

        for term in tokens:
            if term not in self._postings:
                continue

            postings = self._postings[term]
            # Inverse Document Frequency
            idf = math.log(1.0 + (self._total_docs / len(postings)))

            for doc_id in postings:
                tf = self._term_frequencies[term][doc_id] / self._doc_lengths[doc_id]
                scores[doc_id] += tf * idf

        ranked = sorted(scores.items(), key=lambda x: x[1], reverse=True)
        return [(doc_id, round(score, 4)) for doc_id, score in ranked[:limit]]

# ==============================================================================
# MemForge Storage Engine - Master Multi-Model Engine Facade (Milestone 12)
# ==============================================================================

import json
from dataclasses import dataclass, asdict
from typing import Any, Dict, List, Optional

from memforge.core.buffer import ContiguousBuffer, FixedRecordArray
from memforge.core.hash_map import MemForgeHashMap
from memforge.cache.lru_cache import LRUBufferPool
from memforge.index.btree import MemBTreeIndex
from memforge.index.trie import AutocompleteSearchEngine
from memforge.index.inverted_index import InvertedIndex
from memforge.graph.relationship import GraphRelationshipEngine
from memforge.txn.undo_log import TransactionUndoLog


@dataclass
class Document:
    """Discrete domain entity containing structured attributes, text, and numerical metrics."""
    doc_id: int
    title: str
    body_text: str
    price: float
    category: str


class MemForgeEngine:
    """
    CAPSTONE MULTI-MODEL DATABASE COORDINATOR:
    Unites all 12 milestones into a unified in-memory database system.
    """
    def __init__(self, wal_capacity: int = 10 * 1024 * 1024, cache_pages: int = 64):
        # Ch 01: Low-level binary buffer and physical offset array
        self._wal = ContiguousBuffer(capacity_bytes=wal_capacity)
        self._record_offsets = FixedRecordArray()

        # Ch 02: Primary key associative directory
        self._primary_index = MemForgeHashMap()

        # Ch 04: LRU buffer pool for cached deserialized documents
        self._cache = LRUBufferPool(capacity_pages=cache_pages)

        # Ch 07: Transaction undo log for rollback protection
        self._undo_log = TransactionUndoLog()

        # Ch 09: Multi-way B-Tree secondary range index on price
        self._price_btree = MemBTreeIndex(degree=3)

        # Ch 10: Prefix Trie for title autocomplete
        self._typeahead = AutocompleteSearchEngine()

        # Ch 11: Entity relationship network graph
        self._relations = GraphRelationshipEngine()

        # Ch 12: Inverted Index for body_text full-text search
        self._fulltext = InvertedIndex()

    def insert_document(self, doc: Document) -> None:
        """
        MULTI-MODEL INGESTION PIPELINE:
        Serializes to binary WAL, records offsets, updates primary and secondary indexes.
        """
        # 1. Serialize document to JSON bytes and write to contiguous WAL
        raw_payload = json.dumps(asdict(doc)).encode("utf-8")
        start_offset, length = self._wal.write(raw_payload)

        # 2. Append offset to fixed index array
        rec_id = self._record_offsets.append_offset(start_offset)

        # 3. Primary Key Index (MemForgeHashMap)
        self._primary_index[doc.doc_id] = (start_offset, length)

        # 4. Cache in LRU Buffer Pool
        self._cache.put_page(doc.doc_id, doc)

        # 5. Multi-Way B-Tree Secondary Range Index (Price)
        self._price_btree.insert(doc.price, doc.doc_id)

        # 6. Prefix Trie (Title Autocomplete)
        self._typeahead.insert(doc.title.lower(), doc.doc_id, weight=int(doc.price))

        # 7. Inverted Index (Body Full-Text Search)
        self._fulltext.index_document(doc.doc_id, doc.body_text)

        # 8. Record compensating action in Undo Log for rollback safety
        self._undo_log.append_undo_action("DELETE_INSERTED", key=str(doc.doc_id), previous_value=None)

    def get_by_id(self, doc_id: int) -> Optional[Document]:
        """Instant O(1) document retrieval via LRU Cache or WAL offset."""
        cached = self._cache.get_page(doc_id)
        if cached:
            return cached

        # Cache miss: fetch binary payload from WAL via primary index
        offset_info = self._primary_index.get(doc_id)
        if not offset_info:
            return None

        start, length = offset_info
        raw_view = self._wal.read_zero_copy(start, length)
        doc_dict = json.loads(raw_view.tobytes().decode("utf-8"))
        doc = Document(**doc_dict)
        self._cache.put_page(doc_id, doc)
        return doc

    def query_price_range(self, min_price: float, max_price: float) -> List[int]:
        """Sub-millisecond range query using Multi-Way B-Tree."""
        return self._price_btree.range_scan(min_price, max_price)

    def suggest_titles(self, prefix: str, limit: int = 5) -> List[str]:
        """O(L) prefix autocomplete suggestions using Trie."""
        return [term for term, _ in self._typeahead.autocomplete(prefix.lower(), limit=limit)]

    def search_fulltext_and(self, terms: List[str]) -> List[int]:
        """Boolean AND full-text search across document bodies."""
        return self._fulltext.search_boolean_and(terms)

    def search_fulltext_ranked(self, query: str, limit: int = 5) -> List[Tuple[int, float]]:
        """TF-IDF ranked relevance full-text search."""
        return self._fulltext.search_ranked_tfidf(query, limit=limit)

    def link_documents(self, src_id: int, dst_id: int, cost: float = 1.0) -> None:
        """Creates a directed relationship between two entities."""
        self._relations.add_relationship(str(src_id), str(dst_id), weight=cost)

    def find_relationship_path(self, src_id: int, dst_id: int) -> Tuple[float, List[str]]:
        """Calculates the lowest-cost connection path using Dijkstra."""
        return self._relations.shortest_path_dijkstra(str(src_id), str(dst_id))

import pytest
from memforge.engine import MemForgeEngine, Document

class TestMemForgeCapstoneEngine:
    """End-to-End integration test validating all multi-model storage and indexing subsystems."""

    def test_full_multi_model_lifecycle(self):
        engine = MemForgeEngine()

        # 1. Ingest Documents into Multi-Model Engine
        doc1 = Document(
            doc_id=1,
            title="PostgreSQL Internals",
            body_text="Database buffer pool and write ahead logging transaction safety.",
            price=45.0,
            category="Systems"
        )
        doc2 = Document(
            doc_id=2,
            title="Python High Performance",
            body_text="Optimizing CPython memory layout with bytearray and contiguous buffers.",
            price=35.0,
            category="Programming"
        )
        doc3 = Document(
            doc_id=3,
            title="Distributed Algorithms",
            body_text="Consensus algorithms in distributed database transaction systems.",
            price=60.0,
            category="Systems"
        )

        engine.insert_document(doc1)
        engine.insert_document(doc2)
        engine.insert_document(doc3)

        # 2. Verify Primary Key O(1) Lookups (Hash Map + LRU Cache)
        retrieved = engine.get_by_id(1)
        assert retrieved is not None
        assert retrieved.title == "PostgreSQL Internals"
        assert retrieved.price == 45.0

        # 3. Verify B-Tree Range Scans ($30.00 to $50.00)
        # Matches doc2 ($35) and doc1 ($45), excludes doc3 ($60)
        price_matches = engine.query_price_range(30.0, 50.0)
        assert sorted(price_matches) == [1, 2]

        # 4. Verify Prefix Trie Autocomplete
        suggestions = engine.suggest_titles("post")
        assert "postgresql internals" in suggestions

        # 5. Verify Inverted Index Boolean AND Search
        # Query: "database" AND "transaction" -> Matches doc1 and doc3
        bool_matches = engine.search_fulltext_and(["database", "transaction"])
        assert sorted(bool_matches) == [1, 3]

        # 6. Verify Inverted Index TF-IDF Ranked Relevance
        # Query: "logging buffer" -> doc1 has both terms, ranks #1
        ranked = engine.search_fulltext_ranked("logging buffer")
        assert len(ranked) >= 1
        assert ranked[0][0] == 1  # Top doc_id is 1

        # 7. Verify Graph Entity Relationship Routing (Dijkstra)
        engine.link_documents(src_id=1, dst_id=2, cost=2.5)
        engine.link_documents(src_id=2, dst_id=3, cost=1.5)
        engine.link_documents(src_id=1, dst_id=3, cost=10.0)

        # Direct path 1 -> 3 costs 10.0; Shortest path 1 -> 2 -> 3 costs 4.0
        cost, path = engine.find_relationship_path(src_id=1, dst_id=3)
        assert cost == 4.0
        assert path == ["1", "2", "3"]
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ Quadratic Boolean Set Intersections

Converting posting lists to Python sets: set(l1) & set(l2) for every search query.

Why this destroys search throughput: Allocating new Python sets and hashing millions of Document IDs on every search wastes CPU and thrashes RAM. Because posting lists are naturally stored in sorted order, the Two-Pointer Sweep intersects lists in $O(L_1 + L_2)$ time with zero set allocation!

❌ Unindexed Foreign Key Scanning

Scanning the entire database table to resolve entity relationships: [d for d in db if d.author_id == id].

Why this causes slow queries: Table scans are $O(N)$. Graph relationship layers should maintain an explicit Adjacency List, allowing immediate $O(1)$ neighbor resolution!
