Part 01

Computer Science: The Test Double Taxonomy & Protocol Boundaries

In software engineering, the term "mock" is casually used to describe any replacement of a production dependency. However, conflating different test doubles leads to brittle test architectures. Gerard Meszaros formalized the canonical Test Double Taxonomy in xUnit Test Patterns:

Dummy Placeholder

Objects passed around to satisfy signature parameters, but never actually invoked or inspected (e.g., an unreferenced token).

Zero behavior • Static filler
Stub Canned Data

Provides hardcoded answers to calls made during the test. Responds deterministically without verifying interaction counts.

Provides indirect inputs
Spy Observer

Wraps a real object to secretly record invocation metadata (arguments, call counts, return values) while executing real code.

Real logic + Telemetry
Mock Expectation

Pre-programmed with strict expectations of which calls it must receive. Fails the test if calls happen out of order or with wrong arguments.

Behavioral verification
Fake Senior Choice

Has a working business implementation, but takes shortcuts making it unsuitable for production (e.g., in-memory dictionary rates).

Most robust • Zero drift
Architectural Paradigm: Mockist vs. Classicist (Protocol-Driven Fakes)

Why Staff Engineers Decouple Interfaces with typing.Protocol

1. Brittle Mockist Approach High Maintenance

Tests mock low-level private methods or direct HTTP client instances:

mocker.patch("httpx.AsyncClient.get")
assert mock_client.get.call_count == 1
  • Couples tests directly to third-party library implementation details.
  • If HTTPX is swapped for a gRPC client, 100% of your tests break even if the business logic works!
  • Subject to "Mock Drift" (mock returns structures that production APIs no longer send).
2. Staff Standard: Protocol + Fake Adapter Refactor-Proof

Define a structural subtyping interface (typing.Protocol) for the boundary:

class RatesProvider(Protocol): async def get_rate(...)
class FakeRatesProvider(RatesProvider): # in-memory dict
  • Domain services depend strictly on the abstract Protocol.
  • Tests inject FakeRatesProvider: runs in 0.001ms, $0 cost, zero network flakiness.
  • Mypy statically enforces that the Fake and Real clients never drift!
Part 02

The Mechanics of Safe Mocking: Namespaces & autospec=True

When you must use mocks (for example, testing network error conditions or verifying telemetry calls), using Python's standard unittest.mock.patch directly is dangerous: manual patches can leak across test boundaries if an exception halts cleanup. We mandate the pytest-mock plugin (via the mocker fixture), which guarantees LIFO teardown.

The Golden Rule of Patching: Patch Where an Object is Looked Up, Not Where Defined!
✗ The Where-Defined Mistake
Suppose vaultflow.services.rates_oracle executes:
from httpx import AsyncClient
If your test patches where it was defined:
mocker.patch("httpx.AsyncClient")

FAILURE: rates_oracle already holds a direct reference to the original AsyncClient in its local namespace! The patch has zero effect; live HTTP calls continue leaking.

✓ The Where-Looked-Up Rule
Patch the reference inside the target consumer's module namespace:
mocker.patch("vaultflow.services.rates_oracle.AsyncClient")

SUCCESS: PyTest intercepts the symbol lookup inside rates_oracle. When the service instantiates the client, it receives the mock instance cleanly.

Eliminating Mock Drift with autospec=True:

By default, Python's MagicMock accepts any attribute or method call whatsoever. If an engineer renames a production method from fetch_spot_rate() to get_spot_quote(), but forgets to update the test suite, a naive mock will happily accept the old call without raising an error!

mocker.patch("vaultflow.services.rates_oracle.BloombergClient", autospec=True)

With autospec=True, PyTest inspects the real class's signature. If your test or application invokes a method that does not exist or passes incorrect argument counts, PyTest immediately raises an informative AttributeError or TypeError!

Part 03

Zero-Cost Network Testing: Transport Interception via respx

When testing an HTTP client that communicates with paid external oracles (e.g., Bloomberg B-PIPE, Refinitiv, or a SWIFT gateway), mocking the client class itself bypasses your serialization, deserialization, headers, and error handling logic.

The senior standard is **Network-Level Transport Interception** using respx. respx hooks directly into HTTPX's transport layer. The real production client runs, real JSON parsers execute, real headers are evaluated—but outgoing TCP network packets are intercepted in memory:

The In-Memory HTTP Transport Interception Architecture
1. BloombergClient Executes real httpx.AsyncClient.get()
→ ASGI Transport →
2. respx Mock Router Matches URL pattern • Intercepts raw TCP socket
→ In-Memory Stream →
3. Deterministic Wire Returns 200 OK, 429 Too Many Requests, or Timeout in 0ms! 
# Intercepting Bloomberg Rate API with zero live network calls:
import respx
from httpx import Response

@respx.mock
async def test_rate_feed_resilience_under_rate_limiting():
    # 1. Setup mock route returning HTTP 429 Too Many Requests
    route = respx.get("https://api.bloomberg.test/v1/fx/spot").mock(
        return_value=Response(429, headers={"Retry-After": "30"})
    )

    client = BloombergRatesClient(base_url="https://api.bloomberg.test")
    
    # 2. Assert client handles rate limits gracefully without crashing
    with pytest.raises(RateLimitExceededError):
        await client.fetch_live_rate("EUR", "USD")

    assert route.called
    assert route.call_count == 1
Part 04

Behavioral Telemetry: Spying on State-Machine Circuit Breakers

In high-frequency clearing systems, when an external oracle experiences an outage, continuing to fire HTTP calls causes cascading request timeouts and thread exhaustion. A **Circuit Breaker** monitors boundary failures and transitions across three states:

1. CLOSED Normal

All requests pass through to the primary provider. Failures increment an internal error counter.

2. OPEN Tripped

After $N$ consecutive failures (e.g., 3), the circuit trips! Outgoing calls are aborted instantly, routing traffic to a secondary backup feed.

3. HALF_OPEN Testing

After a recovery cooldown, a single probe request is permitted. If successful, resets to CLOSED; if it fails, reverts to OPEN.

To test a circuit breaker, replacing it with a mock defeats the purpose—you need the real state machine to execute! We use mocker.spy: it wraps the production method, allowing real state transitions while providing assertion capabilities over invocation history.

1. Rates Oracle & Circuit Breaker: src/vaultflow/services/rates_oracle.py Boundary Architecture 
# ==============================================================================
# VaultFlow Services - Resilient Rates Oracle & Circuit Breaker (Milestone 04)
# ==============================================================================

import time
from decimal import Decimal
from enum import Enum
from typing import Protocol, Dict, Optional
import httpx
from vaultflow.core.money import FinancialDomainError

class OracleConnectionError(FinancialDomainError):
    """Raised when an external rates gateway is unreachable or timing out."""
    pass

class RateLimitExceededError(FinancialDomainError):
    """Raised when the third-party oracle returns HTTP 429 Too Many Requests."""
    pass

class CircuitBreakerOpenError(FinancialDomainError):
    """Raised when operations are rejected due to an OPEN tripped circuit breaker."""
    pass

# ------------------------------------------------------------------------------
# STRUCTURAL SUBTYPING: The Rates Provider Interface
# Eliminates mock drift by enabling Mypy to verify Fakes and Real Clients!
# ------------------------------------------------------------------------------
class RatesProviderProtocol(Protocol):
    async def get_spot_rate(self, base_currency: str, quote_currency: str) -> Decimal:
        ...


class CircuitState(Enum):
    CLOSED = "CLOSED"        # Healthy: calls pass through
    OPEN = "OPEN"            # Tripped: calls fail fast
    HALF_OPEN = "HALF_OPEN"  # Cooldown: testing recovery with probe


class CircuitBreaker:
    """State-machine protecting downstream services from cascading network outages."""
    def __init__(self, failure_threshold: int = 3, recovery_timeout_seconds: float = 30.0):
        self.failure_threshold = failure_threshold
        self.recovery_timeout_seconds = recovery_timeout_seconds
        self.state = CircuitState.CLOSED
        self.failure_count = 0
        self.last_state_change = time.monotonic()

    def record_success(self) -> None:
        self.failure_count = 0
        self.state = CircuitState.CLOSED

    def record_failure(self) -> None:
        self.failure_count += 1
        if self.failure_count >= self.failure_threshold:
            self.state = CircuitState.OPEN
            self.last_state_change = time.monotonic()

    def before_execution(self) -> None:
        if self.state == CircuitState.OPEN:
            elapsed = time.monotonic() - self.last_state_change
            if elapsed >= self.recovery_timeout_seconds:
                self.state = CircuitState.HALF_OPEN
            else:
                raise CircuitBreakerOpenError(f"Circuit breaker is OPEN. Cooldown remaining: {self.recovery_timeout_seconds - elapsed:.1f}s")


class BloombergLiveRatesClient:
    """Production client communicating over HTTP to paid market oracles."""
    def __init__(self, base_url: str = "https://api.bloomberg.test", timeout: float = 2.0):
        self.base_url = base_url
        self.timeout = timeout

    async def get_spot_rate(self, base_currency: str, quote_currency: str) -> Decimal:
        url = f"{self.base_url}/v1/fx/spot/{base_currency}{quote_currency}"
        async with httpx.AsyncClient(timeout=self.timeout) as client:
            try:
                response = await client.get(url)
            except (httpx.TimeoutException, httpx.NetworkError) as exc:
                raise OracleConnectionError(f"Connection failed to {url}") from exc

        if response.status_code == 429:
            raise RateLimitExceededError("Bloomberg rate limit exceeded (HTTP 429)")
        if response.status_code != 200:
            raise OracleConnectionError(f"Oracle returned unexpected HTTP status: {response.status_code}")

        payload = response.json()
        return Decimal(str(payload["rate"]))


class ResilientRatesService:
    """Orchestrator wrapping primary provider with circuit breaker & fallback feed."""
    def __init__(
        self,
        primary_provider: RatesProviderProtocol,
        fallback_provider: RatesProviderProtocol,
        circuit_breaker: Optional[CircuitBreaker] = None
    ):
        self.primary = primary_provider
        self.fallback = fallback_provider
        self.breaker = circuit_breaker or CircuitBreaker()

    async def get_rate(self, base_currency: str, quote_currency: str) -> Decimal:
        try:
            self.breaker.before_execution()
            rate = await self.primary.get_spot_rate(base_currency, quote_currency)
            self.breaker.record_success()
            return rate
        except (OracleConnectionError, RateLimitExceededError, CircuitBreakerOpenError):
            # Primary failed or circuit tripped: trip breaker & route to fallback feed!
            self.breaker.record_failure()
            return await self.fallback.get_spot_rate(base_currency, quote_currency)

# VaultFlow Test Suite - Rates Oracle Boundary Tests (Milestone 04)
# ==============================================================================

import pytest
import respx
from decimal import Decimal
from httpx import Response
from vaultflow.services.rates_oracle import (
    RatesProviderProtocol,
    BloombergLiveRatesClient,
    ResilientRatesService,
    CircuitBreaker,
    CircuitState,
    RateLimitExceededError,
    OracleConnectionError
)

# ------------------------------------------------------------------------------
# IN-MEMORY FAKE ADAPTER: Conforms strictly to RatesProviderProtocol
# ------------------------------------------------------------------------------
class FakeRatesProvider:
    def __init__(self, canned_rates: dict[str, Decimal]):
        self.rates = canned_rates

    async def get_spot_rate(self, base_currency: str, quote_currency: str) -> Decimal:
        pair = f"{base_currency}{quote_currency}"
        if pair not in self.rates:
            raise OracleConnectionError(f"No rate for {pair}")
        return self.rates[pair]


@pytest.mark.unit
class TestRatesOracleBoundaries:
    """Validates network boundary isolation, respx mocking, and circuit breakers."""

    @respx.mock
    async def test_bloomberg_client_parses_wire_rate_successfully(self):
        # Intercept wire HTTP call: returns simulated EURUSD = 1.0850 without live network!
        respx.get("https://api.bloomberg.test/v1/fx/spot/EURUSD").mock(
            return_value=Response(200, json={"rate": "1.0850", "timestamp": 1700000000})
        )

        client = BloombergLiveRatesClient(base_url="https://api.bloomberg.test")
        rate = await client.get_spot_rate("EUR", "USD")

        assert rate == Decimal("1.0850")

    @respx.mock
    async def test_bloomberg_client_translates_429_to_domain_exception(self):
        respx.get("https://api.bloomberg.test/v1/fx/spot/EURUSD").mock(
            return_value=Response(429, json={"error": "rate_limit_exceeded"})
        )

        client = BloombergLiveRatesClient(base_url="https://api.bloomberg.test")
        
        with pytest.raises(RateLimitExceededError, match=r"Bloomberg rate limit exceeded"):
            await client.get_spot_rate("EUR", "USD")

    @respx.mock
    async def test_circuit_breaker_trips_to_open_and_falls_back(self, mocker):
        # 1. Arrange: Primary Bloomberg mock returns repeated 503 Server Errors
        respx.get("https://api.bloomberg.test/v1/fx/spot/EURUSD").mock(
            return_value=Response(503, text="Service Unavailable")
        )
        primary_client = BloombergLiveRatesClient(base_url="https://api.bloomberg.test")
        
        # Fallback provider holds offline contingency rate: 1.0800
        fallback_fake = FakeRatesProvider(canned_rates={"EURUSD": Decimal("1.0800")})

        # Spy on the real state machine using mocker.spy!
        breaker = CircuitBreaker(failure_threshold=3, recovery_timeout_seconds=60.0)
        spy_record_failure = mocker.spy(breaker, "record_failure")

        service = ResilientRatesService(
            primary_provider=primary_client,
            fallback_provider=fallback_fake,
            circuit_breaker=breaker
        )

        # 2. Act: Trigger 3 failures to trip the circuit
        for i in range(3):
            rate = await service.get_rate("EUR", "USD")
            # Verify fallback answered seamlessly without crashing callers
            assert rate == Decimal("1.0800")

        # 3. Assert: Verify Breaker state and spy metrics
        assert breaker.state == CircuitState.OPEN
        assert spy_record_failure.call_count == 3

        # 4. 4th Call: Must fail-fast on primary (zero HTTP calls!) and route directly to fallback
        rate_4 = await service.get_rate("EUR", "USD")
        assert rate_4 == Decimal("1.0800")
        # HTTP route was called exactly 3 times, NOT 4! Breaker blocked 4th call!
        assert len(respx.calls) == 3
Warning Track

Beginner Pitfalls & Architectural Anti-Patterns

❌ The "Over-Mocked Fantasy" Anti-Pattern

Writing mocker.patch.object(service, "_calculate_spread", return_value=5).

Why this causes production outages: Mocking internal private helper methods locks your tests to volatile implementation details. If you refactor _calculate_spread, your tests pass 100% green while production crashes. Rule: Never mock private methods. Mock only structural boundaries (network I/O, disk writes, time).

❌ Unrestricted Network Leaks in CI

Allowing integration tests to invoke live external APIs without socket guards.

Why this is dangerous: A developer creates an infinite loop or tests run on 8 parallel CI workers, executing 10,000 live calls against a paid financial gateway ($1,000+ cloud bill) or triggering an IP ban. Fix: Use socket-blocking fixtures (such as pytest-socket) to ensure tests crash if real network calls are attempted!
