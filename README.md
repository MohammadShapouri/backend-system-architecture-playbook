# Backend & System Architecture Playbook

This repository contains **14 complete, production-grade courses** written in a highly detailed, visually rich HTML format. It bridges the gap between theoretical computer science and real-world enterprise engineering using Python, FastAPI, SQLAlchemy 2.0, Redis, Docker, Kubernetes, and modern cloud architectures.

## Curriculum Tracks

The curriculum is divided into 14 modular courses across 5 progressive tracks, each containing a series of chapters, architectural diagrams, real-world metaphors, production code bases, and PyTest batteries.

### Track 1: Foundations & Language Mastery
*   **Web Architecture & Engineering:** Client-Server physics, REST, UI rendering, and deployment.
*   **Python OOP - Intermediate:** State management, encapsulation, and class anatomy.
*   **Python OOP - Advanced:** Dunder protocols, Metaprogramming, C3 Linearization, and Descriptors.
*   **Python Data Structures:** Contiguous memory, Hash Maps, Tries, Heaps, and B-Trees.

### Track 2: Core Backend Engineering
*   **Backend Course (FastAPI):** Request routing, Pydantic v2 schemas, Dependency Injection, and Middleware.
*   **SQLAlchemy 2.0 Course:** Connection pooling, unit of work, asynchronous mapping, and schema evolution.
*   **PyTest Engineering:** AST rewriting, parameterization, mocks, and asynchronous test harnesses.
*   **PyJWT & Token Auth:** Asymmetric RSA signing, RFC 7519 claims, and zero-trust federation.

### Track 3: High-Performance & Reliability
*   **Design Patterns:** GoF Creational/Structural/Behavioral patterns, CQRS, Sagas, and Outbox patterns.
*   **Caching Architectures:** L1/L2 coherency, Cache-Aside, Write-Behind, ARC, and XFetch Stampede defense.
*   **Rate Limiting:** Distributed Token Buckets, Sliding Window Counters, and Lua atomicity.

### Track 4: DevOps, CI/CD & Enterprise Observability
*   **Git & GitHub Architecture:** Cryptographic object store DAG, Three Trees, reflog recovery, PR governance, and GitHub Actions CI/CD pipelines.
*   **Enterprise Logging & Observability:** QueueHandler async telemetry, W3C trace correlation, PII masking, Docker/K8s DaemonSets, Loki log ingestion, and SRE post-mortems.

### Track 5: Cloud Scale & Distributed Systems
*   **System Design:** Back-of-the-envelope math, BGP Anycast, L4/L7 load balancing, Raft consensus, and Kafka log streaming.

## How to Navigate this Repository

This project includes a beautiful, interactive **HTML Master Navigator**. 

To begin your journey:
1. Clone this repository to your local machine.
2. Open `index.html` in your web browser.
3. Use the unified dashboard to jump into any specific course's Series Navigator.
